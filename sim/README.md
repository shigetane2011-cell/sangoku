# 戦闘シミュレータ（v0.3 検証用）

仕様書 v0.2.1 の §5〜§8 を実装し、§4.6 のバランス指標が実際に測定できるかを確かめるための
検証環境。ゲーム本体ではなく、**数値設計の妥当性を測るための道具**である。

外部ライブラリは不要（Python 3.10 以上の標準ライブラリのみ）。

## ファイル

| パス | 内容 |
| --- | --- |
| `cards.json` | 武将サンプル24枚。能力値と必殺技のデータ。 |
| `engine.py` | 部隊戦の戦闘エンジン。§8.1 の12ステップをティックごとに処理する。 |
| `balance.py` | バランス検証ハーネス。§4.6 の指標を実測する。 |
| `budget.py` | 兵種ごとのステータス予算を検算する。カードを追加・変更したら必ず通す。 |

## 実行

```
cd sim
python3 engine.py            # 1戦を実況付きで再生（動作確認）
python3 balance.py check     # 決定論・戦闘時間・決着理由・必殺技回数
python3 balance.py troops    # 兵種三すくみ（合計コストを揃えて比較）
python3 balance.py commander # 総大将の前衛配置と後衛配置の勝率差
python3 balance.py swap      # 差し替え勝率（§4.6 目標 47-53%）
python3 balance.py meta      # 採用率（§4.6 目標 上限30% / 下限3%）
python3 balance.py all       # すべて
python3 budget.py            # 兵種ごとのステータス予算の検算
```

`swap` と `meta` は数万回の対戦を行うため、数分かかる。

## カードを追加・変更したときの手順

1. `cards.json` を編集する。
2. `python3 budget.py` を通し、総合値/コストのぶれが許容内に収まっていることを確認する。
   **ここを飛ばすと、以降のバランス調整がすべて無駄になる。** v0.3 の初期データは
   総合値/コストが 歩兵556 / 騎兵701 / 弓兵304 と割れており、兵種補正や射程を
   いくら調整しても弓兵の勝率0%が動かなかった。
3. `python3 balance.py troops` で三すくみの向きを確認する。
4. `python3 balance.py check` で戦闘時間と必殺技の発動回数を確認する。
5. `python3 balance.py swap` / `meta` で §4.6 の指標を測る。

## 実装上の約束

仕様書 §8.4 の再現性要件に対応する。

- **すべて整数演算**。浮動小数点は一切使わない。位置と射程は1単位=10、必殺技ゲージは最大100を10000で保持する。
- **乱数は xorshift64\* をシードから回す**。消費順序は §8.1 の処理順序に厳密に従う。
- **同じ (編成, 配置, 戦場条件, シード) なら必ず同じ結果**になる。`balance.py check` が毎回検証する。
- 先攻側もシードから決定論的に決まる。

## 仕様書との差分

実装にあたって仕様書に無い判断が必要だった箇所、および実測の結果として仕様書側を
変更すべきと判断した箇所は、仕様書 v0.3 の §0.3 に一覧としてまとめる。主なものは以下。

- 弓兵の標的選択を「射程内で残兵力率が最も低い敵」とした。総大将を名指しで狙わせると、
  部隊戦が「どちらが先に総大将を落とすか」の競争に収束し、編成と配置が結果に
  反映されなくなるため。
- 必殺技ゲージの時間経過分を 1.0/秒 から 2.0/秒 へ引き上げた。v0.2.1 の
  「60秒で1回目・平均1.2回・上限90秒」は同時に満たせないため（2回目に更に60秒必要）。
- 決着促進を追加した。導入前は部隊戦の31%が時間切れ決着だった。

## カードデータの見方

`cards.json` の1枚はこの形式。

```json
{
  "id": "choryo_shoyoshin", "person": "張遼", "name": "張遼〔逍遥津〕", "tier": "mid",
  "cost": 6, "troop": "cav", "hp": 3870, "atk": 66, "dfn": 48, "speed": 13,
  "gauge_rate": 105, "acc": 92, "crit": 14,
  "skill": {"name": "突撃", "target": "front_enemy",
            "effects": [{"type": "damage", "power": 175}]}
}
```

- `person` は人物ID（§4.3 の重複判定の単位）、`id` は武将カードID。
- `troop` は `inf`（歩兵）/ `cav`（騎兵）/ `arc`（弓兵）。攻撃間隔・射程・回避の
  兵種標準値は `troop_defaults` にまとめてある。
- `gauge_rate` は100が標準（1.0倍）。
- `speed` は1秒あたりの前進量（レーン奥行きは100単位）。

必殺技の `target` と `effects[].type` に指定できる値は `engine.py` の
`skill_targets()` と `cast()` を参照。

| target | 対象 |
| --- | --- |
| `front_enemy` | 正面の敵（自レーンの前衛優先） |
| `lane_enemies` | 自レーンの敵全体 |
| `enemy_back_lane` | 自レーンの敵後衛 |
| `enemy_lowest` | 敵全体のうち残兵力が最小 |
| `all_enemies` / `all_allies` | 敵全体 / 味方全体 |
| `lane_allies` / `lowest_ally` / `self` | 自レーンの味方 / 最も兵力の低い味方 / 自分 |

| type | 効果 |
| --- | --- |
| `damage` | `power` は攻撃力に対する% |
| `mod` | `stat`（atk/dfn/acc/speed）を `value`% だけ増減、`duration` ティック |
| `stun` | `duration` ティックのあいだ行動阻害 |
| `dot` | `interval` ティックごとに継続ダメージ |
| `gauge` | 必殺技ゲージを増減（10000が最大） |
