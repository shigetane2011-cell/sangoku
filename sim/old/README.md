# 旧実装（保管のみ・動かさないこと）

レーン（3本の平行通路）と総大将（撤退したら即敗北）を前提にした v0.5 までの実装。
どちらも設計判断として撤回済み。

| 撤回したもの | 理由 | 置き換え先 |
| --- | --- | --- |
| レーン | 三国志の戦場に3本の平行通路は不自然 | 位置ベース（連続 x,y）。`sim/field.py` |
| 総大将 | コストの加算性が壊れる原因だった | 残存20%割れで潰走 |

いまの実装は `sim/field.py` / `sim/design.py` / `sim/rosterdata.py`。

**ここで測った数値は現行エンジンと違う答えを返す。** 過去の記述の出どころを確認する
ためだけに残してある。仕様書 §13 の「測定が嘘をついた」事例と同じ形で、古い計器の
数字を持ち出すのが一番危ない。

| ファイル | 内容 |
| --- | --- |
| `engine.py` | レーン前提の戦闘エンジン |
| `balance.py` | 上のエンジン用のバランス検証ハーネス |
| `roster.py` | `cards.json` の生成器（60人・旧スケール） |
| `budget.py` | `cards.json` の能力値検算 |
| `cards.json` | `roster.py` が生成した旧データ |
