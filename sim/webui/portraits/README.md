# 顔絵の差し替え（§7.59）

このフォルダに **人物名そのままのファイル名** で画像を置くと、武将一覧・編成
画面の顔絵が差し替わります。

    例: 趙雲.png / 曹操.jpg / 貂蝉.webp / 孫尚香.svg

- 対応形式: png / jpg / jpeg / webp / svg（同名が複数あれば png が優先）
- 推奨は **縦3:4**（例 240×320）。違う比率でも中央を切り抜いて表示します
- ファイルが無い人物は、勢力色＋姓の一字の生成プレースホルダが出ます
- **素材の出所とライセンスは置く人が確認すること。** ゲーム側は何も焼き込みません

## 絵を発注する / 生成するとき

**docs/design/portrait-brief.md**（依頼書）と **docs/design/portrait-list.csv**
（120人ぶんの一覧・優先順つき）をそのまま渡せばよい。切り抜きに耐える構図の
条件と、画風・勢力色・権利まわりの注意が全部そこに書いてある。
