# 宝物絵（差し替え式）

このフォルダに **「キー.png」** を置くと、ホームの日替わり3択と編成画面の
宝物欄にその絵が出る（`/treasure_art/キー.png`）。**絵は焼き込みではなく
差し替え式** — 無ければ画面は今まで通り文字だけで、読めなくはならない
（読み込めた絵だけが現れる）。出所と権利の確認は置く人の責任です。

## 守ってほしいこと

- **正方形・背景透過**（暗い盤の上に置くため）。png のほか webp / jpg / svg 可。
- 目安 **512×512**・1枚 150KB 程度まで（顔絵1枚 約130KB と釣り合わせる。
  大きい元絵は art/README.txt の流儀で縮めてから置く）。
- 画面では 26〜56px まで縮むので、**遠目で形が分かる一品絵**が向く
  （細かい書き文字は潰れる）。
- ファイル名は下の表のとおり**キー名**で（名前は変わることがあるが、
  キーは変わらない）。
