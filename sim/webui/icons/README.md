# アイコン（差し替え式）

画面の兵種印とコスト印はここの PNG をそのまま出す。置き換えれば見た目が
変わる。**絵は焼き込みではなく差し替え式** — 出所と権利の確認は差し替える
人の責任です（こちらからフリー素材を混ぜることはしません）。

## 並び

| ファイル | 使い道 | 目安の寸法 |
| --- | --- | --- |
| `typ-shield.png` | 歩兵 | 128×128 |
| `typ-spear.png` | 槍持ち | 128×128 |
| `typ-bow.png` | 弓兵 | 128×128 |
| `typ-cav.png` | 騎兵 | 128×128 |
| `cost-01.png`〜`cost-10.png` | コスト1〜10の環 | 256×256 |

## 守ってほしいこと

- **背景は透過**（暗い盤の上に置くため）。
- **正方形**で、絵の中心を画の中心に合わせる。画面では 17〜40px まで
  縮めて使うので、細い線は溶ける前提で。
- コスト印は**中央に暗い台座**を残す。数字は画面側で環の中心に重ねるので、
  **絵に数字を描き込まない**（値付けが変わっても絵を作り直さずに済む）。
  台座は差し渡しで画の 4 割以上あると二桁が入る。
- 兵種印は色で見分けがつくように（歩兵と槍は同じ形・同じ色で絵柄だけ違え、
  弓は橙、騎は青、という並びにしてある）。

## 1枚のシートで届いたときは

`tools/icon_cut.py <シート画像>` に通すと、塊ごとに切り分けて上の名前で
書き出す。白背景でも透過つきでもよい（白背景のときは外周から繋がった白
だけを抜くので、盾や馬体の内側の白は残る）。
