## 1. いま何をしているか

**カード1枚ずつの値付けを実測で詰めている。** 発端は「関羽・張飛・諸葛亮・
司馬懿は弱くないか」というテストプレイの問いだった。

直近4コミットでやったこと:

1. `one_ruler` が **対勢力の13枚を一度も測っていなかった**のを直した（§7.111）
2. **槍の値札が 2.2 コスト点ぶん古かった**のを突き止めた（§7.112）
3. 値札を 0.75 → 0 へ。**居残りを外す案は盤面が却下**（§7.112）
4. **帯の中央が騎兵で嵩上げされていた**のを直し、5枚へ床調整（§7.114）

## 2. 次にやること（依頼済み・未着手）

### ★ 司馬懿と張飛を +1 まで強くする（**着手済み・検証だけ残っている**）

テストプレイの指示（2026-08-26）:

> これらの武将のうち司馬懿張飛は➕1くらいまで強くしたい

**評価はやり直さないこと。** 下の数字は測ってある。同じ測定を回し直すと
1時間近く溶かすだけで、結論は変わらない。

**入れたもの**（コミット済み）:

- `field.FLOOR_ADJ_CAP = 0.30` を新設し、`design.derive` と `Unit.__init__` の
  両方をここから引くようにした（以前は 0.10 が2箇所にべた書き）
- 床調整 … 司馬懿 0.29 / 張飛 0.11

**結果**（帯 × 兵種の中央から見た差）:

```
  張飛〔当陽橋〕  ±0.00 → +1.07   ← 狙いどおり
  司馬懿〔冢虎〕  -0.17 → +0.76   ← 届いていない
  プール全体の幅  2.81（-1.12〜+1.69）
```

**司馬懿は床調整では +1 に届かない。** 効きが飽和する — 生の物差しの値で
0.15→+1.09 / 0.20→+1.42 / 0.25→+1.73 / 0.30→+2.02 と、後半は 0.05 あたり
+0.29 まで落ちる（弓10の中央 +0.94 を引くと、上限 0.30 でも +0.8 前後）。
残りを埋めるなら別の器が要る:

| 案 | 中身 | 懸念 |
| --- | --- | --- |
| イ | `FLOOR_ADJ_CAP` をさらに広げる | 兵力 +35% 超。弓兵の兵力はもともと最大で、これ以上は「壁より硬い後衛」になる |
| ロ | コストを 10 → 9 へ | 同じ強さで安くなる＝実質の強化。戦記の持ち込み上限が敵の名目コストから出るので、司馬懿が敵に出る戦が易しくなる |
| ハ | +0.76 で手を打つ | 弓10の中では上位。看板としては十分かもしれない |

**まだやっていない検証（これを回せば終わり）:**

```
python3 tools/ladder_top.py combo    # 約7分。三すくみが崩れていないか
python3 tools/senki_check.py         # 約9分。戦記の坂
```

**両方とも戦記の敵に出る札**なので、「長駆の斧」と同じ形で難所が増える恐れが
ある（下の残課題）。増えていたら、床調整の量ではなく**その戦の敵デッキ**を見る。

### 残課題: 戦記「長駆の斧」が 0%

床調整は**名目のコストを変えずに**実力を上げる。戦記の持ち込み上限は敵の
名目コストから引くので、**床調整の札が敵に集まる戦だけ難しくなる**。徐晃と
張郃を両方 +0.10 したら、その2枚が揃って出る第24戦だけ 67% → 0% に落ちた
（登用もこの2人なので差し替えられない）。

`enemy_cost` に床調整ぶんを足して上限を +1 する直し方は**測って却下**した
（難所が 14戦 → 16戦へ悪化。`suggest_deck` の組み方が上限に対して単調でなく、
上限を上げると別の弱い草案を引く）。直すなら**その戦の敵デッキ**を見ること。

**司馬懿・張飛を強くすると、この問題が広がる**（両方とも戦記の敵に出る）。

### 未決（測ったが採っていない）

- **討ち取りの割増 `design.KILL_PREMIUM` が古い可能性**（§7.112）。規則どおりの
  布陣で掃引すると実測 0.00〜0.42 に対し表は 0.60〜4.94。ただし**同じ計器の
  零点が汚れている**（コスト4の詰め物に囲まれた高コスト札は能力値を足しても
  伸びない）ので書き替えていない。**車台と詰め物のコストを揃えた計器**を作って
  から測り直すこと
- **騎兵の一撃離脱** … `docs/design/cavalry-hit-and-run.md` に案A/B/Cと歯止め。

## 3. 計器の一覧と、それぞれが**測れないもの**

**これがこの企画でいちばん高くつく所である。** 計器は壊れていないのに、
適用範囲の外で読んで間違った結論に至る事故を何度も起こしている。

| 計器 | 用途 | 測れないもの |
| --- | --- | --- |
| `tools/one_ruler.py` | 札1枚の値付け（行ごとの物差し） | **「線を保つ」役目**。1対1の斬り合いしか見ないので**騎兵を過大評価する**。→ 下の落とし穴 |
| `tools/ladder_top.py combo` | 7つの型の総当たり（兵種の釣り合いはここ） | 個別の札 |
| `tools/senki_check.py` | 戦記52戦の坂 | 絶対値は目安（草案の強さは保証されていない）。**形**を見る計器 |
| `tools/skill_price.py` | 必殺技・槍・特性の値段（実測 対 請求） | 零点が汚れる場合がある（下） |
| `python3 -m sim.field traits` | 誘発型の特性の値段 | **釣り合った合成軍では誰も全滅しない** → `self_dead` は必ず 0.0000。`skill_price.py --trait` を使う |
| `python3 -m sim.rosterdata` | CSV・設計式・盤面の三者一致 | 盤面の釣り合い |

### 落とし穴（全部いちど踏んだ）

1. **`one_ruler` の帯の中央を、兵種を混ぜたまま使わない。** 帯の中央は騎兵の
   枚数ぶん嵩上げされる。歩兵の札をそれと比べると、騎兵の過大評価がそのまま
   「この歩兵は安売り」という読みに化ける。**帯 × 兵種**で取ること（§7.114）
2. **兵種ぐるみの読みを値付けの根拠にしない。** 騎兵はここで最もお買い得と
   出るが、盤面では騎兵デッキが最下位（§7.108）
3. **`power_hi`（威力の幅）は種の無い測定では中央値になる。** `margin` 系の
   計器は振れ幅を一切見ない。振れ幅を測るなら `simulate(seed=...)`（§7.113）
4. **特性の値段を測るとき `trait=key` と書くと元の特性を消す。** 測っているのは
   「新しい特性 − 消した特性」になる。重ねること（§7.113）
5. **有り/無しで別のデッキを引かない。** 差が編成のばらつきに埋もれる
   （値 +0.42 に対し標準誤差 0.37 になった）
6. **上限のような量は整数で持つ。** `player_cap` が小数を返すと、草案が上限を
   丸めて組んでから丸めない値と突き合わせ、**組めた編成を自分で弾く**
   （52戦中22戦、のちに9戦。**2回踏んだ**）
7. **エンジンの定数を動かしたら、その挙動に値札が付いていないか数える。**
   `SPEAR_GUARD` を切り替えた回に `SPEAR_PRICE` を測り直さず、9枚が 0.75 を
   払って返り 0 のまま残った（§7.112）
8. **零点の怪しい計器で表を書き替えない**（§7.112 の `KILL_PREMIUM`）
9. **理屈で機構をいじる前に盤面へ聞く。** 「値打ち 0 ＝死んだ語＝機構を戻す
   べき」は筋が通って聞こえたが、外した瞬間に一強が生まれた（§7.112）

## 4. 盤面の主な定数（触るときは必ず測り直す）

```python
# sim/field.py
ACT_COEF   = {INF: 1.0000, CAV: 1.1238, ARC: 0.6450}   # 能力値をこれで割る
DEF_BY_TYPE= {inf: 56.6, cav: 42.3, arc: 34.0}          # 騎兵に耐久役の札は0枚
INT_WEIGHT = {inf: 0.10, cav: 0.10, arc: 0.35}          # 攻撃の武知の配合
SPEAR_GUARD = True      # 後衛の槍は居残る。**外すと⑦魚3弓2槍が一強になる**
SPEAR_REAR  = 0.40      # 後衛からの突きの威力
FORM_DEPTH  = {4: 1.0, 3: 1.0, 2: 1.12}
FORM_PAIR   = {(3,4): -4.2, (4,2): 0.0, (2,3): 0.0}
DETOUR_MID, DETOUR_GAIN = 0.6, 2.0                      # 迂回の判定（§7.108）

# sim/design.py
EFFECT_CAP  = 0.45      # 効果予算はコストの45%まで
SPEAR_PRICE = 0.0       # 返りが0だから請求しない（§7.112）
floor_adj   = ±0.10     # 帯調整の頭打ち。**司馬懿はここに当たっている**

# sim/senki.py
SENKI_EDGE_FRAC = 0.025   # 割合で持つ（固定量だと序盤に5倍きつい・§7.109）
```

**`実力比%` は兵種をまたいで比べられない**（`ACT_COEF` で割ってあるので弓兵は
1.55倍の能力値を持つ）。
