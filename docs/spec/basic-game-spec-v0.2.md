## 三国志 部隊対戦シミュレーション

### 編成研究型・非同期オートバトル － コンセプト仕様 v0.2

- 版: v0.2（v0.1レビュー反映版）
- 作成日: 2026年8月13日
- 状態: コンセプト検討中／確定事項・暫定案・未決事項を併記

> **ゲームの核** 18人の武将を3つのコスト帯へ重複なく配分し、次の対戦相手の直前戦を読みながら、完全自動の3本勝負に備える編成研究型ゲーム。操作技術ではなく、武将選択・配置・相性・相手の変更予測が勝敗を左右する。

**表記：**「確定」は会話で合意済み、「暫定」は本書での推奨案、「未決」は今後決定する項目を示す。本版で新規に追加した数値・規則はすべて「暫定」であり、合意を経て「確定」へ昇格させる。

## 1. 企画概要

本作は、三国志の武将を用いて部隊を組み、登録した部隊が1時間ごとに自動対戦する非同期型の対戦シミュレーションである。プレイヤーは戦闘中に操作を行わず、対戦前の編成と配置に集中する。

初期版では全武将を最初から使用可能とし、入手運ではなく編成の理解度を競う。各対戦はコスト上限の異なる3レギュレーションで構成され、3部隊のうち2勝したプレイヤーがマッチ勝者となる。

### 1.1 設計上の狙い

- 歴史上の知名度や武勇だけでなく、低コスト武将にも明確な採用理由を持たせる。
- 1人の有力武将をどのレギュレーションへ配分するかという、18人全体での資源配分を成立させる。
- 相手の直前戦は見えるが、次戦の確定編成は見えない状態を作り、偵察・対策・ブラフを生む。
- 実況ログを勝敗表示ではなく、次の改善につながる攻略情報として機能させる。

### 1.2 設計の非目標

以下は「今回はやらないこと」として先に固定する。これらは後から追加すると §4.6 のバランス調整をすべて無効化するため、実装時期ではなく方針として先に決める必要がある。

| 非目標 | 内容 | 理由 |
| --- | --- | --- |
| 戦闘能力に影響する課金 | 課金によって武将の能力値・必殺技・コストが変化する要素を導入しない。 | 「全武将を最初から使用可能」「編成の理解度を競う」という前提と両立しない。 |
| 戦闘能力に影響する育成・装備 | レベル、強化、装備による能力差を導入しない。 | 同一カードの性能が人によって異なると、偵察情報と数値検証の両方が成立しなくなる。 |
| 入手要素（ガチャ等） | 武将の入手をランダム化しない。 | 初期版の検証目的が「編成研究が成立するか」であるため。 |
| 戦闘中の操作 | 発動タイミング指定、標的指定、緊急退却などを導入しない。 | v0.1 の確定事項。非同期対戦の前提。 |

収益化を行う場合は、外見（スキン・称号・戦場演出）、リプレイ保存枠、統計閲覧範囲など、戦闘結果に影響しない範囲に限定する。［暫定］

## 3. 1時間ごとの対戦サイクル

次戦相手の直前戦を見て対策できる設計と、試合5分前の編成ロックを両立させる。v0.1 の時間割は「00-05分で結果確定」としていたが、1部隊戦の長さと3戦直列を前提にすると収まらないため、上限90秒（§8.2）から逆算して修正した。

| 時点 | 状態 | プレイヤーができること |
| --- | --- | --- |
| 毎時00分 | 現在のマッチを自動実行 | テキスト実況をリアルタイム閲覧。低→中→高の順に3戦を直列実行（最大4分50秒）。 |
| 00-06分 | 結果確定・ランク更新 | 3戦の結果、勝因、各種戦闘統計を確認。 |
| 06分［暫定］ | 次の対戦相手と戦場条件を告知 | 相手の直前1マッチ（3レギュレーション分）と傾向統計、次戦の戦場条件を閲覧。 |
| 06-55分 | 偵察・編成期間 | 相手の前回編成と戦い方、戦場条件を踏まえ、自分の3部隊・配置・総大将を変更。 |
| 55分 | 編成ロック | 以後の変更は次々回のマッチから反映。相手の今回編成はまだ非公開。 |
| 次の00分 | 次戦開始 | 双方のロック済み編成を公開し、自動戦闘を開始。 |

対戦相手の決定時刻は、マッチング母数や離脱処理を踏まえて調整する。相手決定後にその相手が参加資格を失った場合の扱い（不戦勝・ゴースト差し替え）は未決。

### 3.1 出陣時間と参加制御［暫定・新規］

1時間ごとに偵察と対策の機会があるため、そのままでは在席時間の長さが直接的な強さになり、「編成研究を競う」という狙いが「在席時間を競う」に置き換わる。以下で抑制する。

| 項目 | 暫定案 | 補足 |
| --- | --- | --- |
| 自動参加 | 登録済み部隊は毎時00分に自動参加を継続する。 | 放置していても戦闘とリプレイは発生する。 |
| レート変動上限 | 1日あたり12マッチまでをレート変動対象とする。 | 24戦すべてを追う必要をなくす。 |
| 主戦時間帯 | プレイヤーは連続した任意の時間帯を主戦時間帯として指定できる。 | 指定帯のマッチを優先的にレート対象とする。 |
| 練習戦 | 上限超過分および主戦時間帯外のマッチは練習戦とする。 | 実況・統計・リプレイは残るが、レートと階級は変動しない。 |
| 偵察対象 | 公開スナップショットはレート対象マッチのみから生成する。 | 練習戦で偽装編成を出し、偵察情報を汚す行為を防ぐ。 |
| 不参加時 | 主戦時間帯を設定していない期間は降格しない（昇格もしない）。 | 休止・復帰の敷居を下げる。 |

未決: 上限マッチ数の値、主戦時間帯の指定粒度と変更頻度、練習戦のマッチング母数を本戦と分けるか。

### 3.2 偵察できる情報

閲覧対象は、対戦相手が最後に完了したレート対象1マッチの公開スナップショットとする。相手がその後に変更した内容は分からない。双方に同じ条件で情報を公開する。

v0.1 の「直前1マッチのみ」では、その編成は別のプレイヤーに向けて組まれたものであり、かつ全武将が解放済みで所持情報に価値がないため、読み取れるシグナルが薄い。傾向統計を追加して読み合いの手掛かりを増やす。

| 情報 | 公開方針 | 狙い |
| --- | --- | --- |
| 前回の3部隊 | 武将カード、コスト、兵種、総大将、前後列・左右配置を表示［暫定］ | 何を軸にしたプレイヤーかを読める。 |
| 前回の実況 | 戦闘開始から終了まで全文を閲覧可能 | 実際に機能した連携や崩れた地点を確認できる。 |
| 前回の戦闘統計 | ダメージ、命中、必殺技回数などを表示［暫定］ | 見た目だけでなく機能面を分析できる。 |
| 直近5マッチの傾向 | 採用頻度上位の武将、兵種構成比、配置の偏り、編成変更率［暫定・新規］ | 1マッチだけでは読めない癖を、確定情報を与えずに示す。 |
| 今回の編成 | 戦闘開始まで非公開［暫定］ | 単純な後出し対策ではなく、相手の変更予測を残す。 |
| それ以前の履歴 | 相手には原則非公開。本人は自分の履歴を閲覧可能［暫定］ | 完全な対策表の作成を抑え、直近傾向の読み合いに限定する。 |
| 戦場条件 | 次戦の条件を両者へ同時公開［暫定・新規］ | 運ではなく編成期間中の計画材料とする。 |

> **偵察の意味** 前回と同じ編成を出す、対策を読んで逆に変更する、あえて一部だけ変える、という読み合いを発生させる。前回編成は答えではなく、次戦を推測する材料である。

### 3.3 公開スナップショットの配信条件［暫定・新規］

v0.1 は「それ以前の履歴は相手には原則非公開」としていたが、当事者以外からの取得を想定していなかった。第三者や別アカウントを経由すれば制限が無効になるため、配信条件を定義する。

- 公開スナップショットは、当該マッチの対戦当事者2名に対してのみ配信する。
- 第三者からの参照、識別子を直接指定した取得、公開ランキングからの遷移では取得できない。
- 同一プレイヤーの複数アカウントによる代理偵察は、対戦当事者判定によって自然に遮断される。仕組み上完全には防げないため、多重アカウント対策は運用側で別途扱う。
- 本人は自分の全履歴を閲覧できる。第三者への共有はプレイヤー自身の意思による共有機能（未決）に限る。

## 4. 部隊編成と武将管理

### 4.1 3部隊・18人の編成

| レギュレーション | 人数 | コスト上限［暫定］ | 役割 |
| --- | --- | --- | --- |
| 低コスト戦（名称未定） | 6人 | 18 | 低コスト・専門型武将が中心。 |
| 中コスト戦（名称未定） | 6人 | 30 | 中堅と一部の名将を組み合わせる。 |
| 高コスト戦（名称未定） | 6人 | 40 | 高コスト武将を含む主力部隊を構成する。 |

- 各部隊は必ず6人とし、合計コストがレギュレーション上限以下でなければ登録できない。
- 3部隊を通じて18の人物枠が必要となる。同一人物の別バージョンは併用不可。
- 高コスト戦へ強力な人物を集中するか、3部隊へ戦力を分散するかがマッチ全体の判断になる。
- 3部隊すべてを登録しないとランク戦に参加できない。1部隊でも未登録の場合、当該マッチは参加対象外とする。［暫定］

### 4.2 総大将［暫定・新規］

v0.1 では「総大将撤退」が勝利条件の候補として、また実況例の中に登場していたが、編成規則に定義がなかった。勝利条件に関わる以上、編成の意思決定に直結するため定義する。

| 項目 | 暫定案 |
| --- | --- |
| 指名 | 各部隊の6人のうち1人をプレイヤーが総大将に指名する。指名は必須。 |
| 配置制限 | 配置枠の制限は設けない。前衛に置くことも後衛に隠すことも認める。 |
| 能力補正 | 総大将は最大兵力 +10%、必殺技ゲージ上昇率 +10% を得る。 |
| 撤退時の影響 | 総大将が撤退した時点で、その部隊戦は敗北とする（§8.2）。 |
| 味方への影響 | 総大将の撤退時、残存する味方全員の攻撃力 −15%（士気低下）。ただし勝敗は §8.2 で即座に決まるため、引き分け判定用の統計に影響する。 |
| 公開範囲 | 総大将は公開スナップショットに含める。今回の指名は戦闘開始まで非公開。 |

これにより「総大将を前衛に置いて補正を活かすか、後衛に隠して安全を取るか」という判断が生まれ、配置の読み合いに軸がひとつ増える。

未決: 補正値、総大将撤退を即敗北とするか残存兵力判定に委ねるか（§8.2 で両案を併記）。

### 4.3 同一人物と別バージョン

武将の実在人物を表す「人物ID」と、時代・逸話・兵種・性能が異なる「武将カードID」を分離して管理する。重複判定は人物IDで行う。

| 人物ID | 武将カード例 | 同一マッチでの扱い |
| --- | --- | --- |
| 曹操 | 曹操〔陳留挙兵〕／曹操〔官渡の覇者〕／曹操〔魏王〕 | 3枚のうち1枚だけ選択可能。 |
| 劉備 | 劉備〔義勇軍〕／劉備〔漢中王〕 | 2枚のうち1枚だけ選択可能。 |

同一人物の別バージョンが異なる必殺技・兵種・コストを持てるかは、原則可能とする暫定案。ただし「人物として同時に存在できない」という制約は維持する。

### 4.4 武将プールとコスト体系［暫定・新規］

v0.1 には武将の総数が記載されていなかったが、プール規模が「18人を配分する」という核の成否を決める。プールが小さすぎると全採用に近くなって配分が成立せず、大きすぎると初期の選択負荷が過大になる。

| 項目 | 暫定値 | 根拠 |
| --- | --- | --- |
| 実装人物数（人物ID） | 60人 | 18人を選ぶと採用率30%。3部隊への配分に意味が出る下限として45人を最低ラインとする。 |
| 実装カード数（武将カードID） | 80枚 | 人気人物に別バージョンを持たせる余地。1人物あたり平均1.3枚。 |
| コスト範囲 | 1〜10 | 整数。低コスト帯1-3、中コスト帯4-6、高コスト帯7-10。 |

コスト上限は「何が成立してほしいか」から逆算して決める。以下が設計意図である。

| レギュレーション | 上限 | 成立させたい編成 | 検算 |
| --- | --- | --- | --- |
| 低コスト戦 | 18（6人平均3） | 中コスト帯を1枚だけ差す構成が可能。高コスト帯は入らない。 | コスト6を1枚入れると残り5枠に12（平均2.4）。コスト7以上は残り5枠が最低コストでも窮屈になる。 |
| 中コスト戦 | 30（6人平均5） | 高コスト帯を1枚は無理なく、2枚は代償付きで採用できる。 | コスト10を1枚で残り5枠に20（平均4）。2枚では残り4枠に10（平均2.5）となり低コスト帯に固定される。 |
| 高コスト戦 | 40（6人平均6.7） | 高コスト帯を2枚まで無理なく、3枚は残り3枠が低コスト帯に固定される。 | コスト10を2枚で残り4枠に20（平均5）。3枚では残り3枠に10（平均3.3）。 |

未決: 各コスト値に何枚のカードを配置するか（分布）。低コスト帯を厚くしないと低コスト戦が単調になる。

### 4.5 余剰コストの扱い［暫定・新規］

6人固定かつコスト上限制のため、コストを余らせても得るものがなく、常に「上限ぴったりに使い切る」が最適になる。これはコスト設計の自由度を下げるため、余剰に小さな価値を与える。

| 案 | 内容 | 評価 |
| --- | --- | --- |
| 案A（推奨） | 余剰コスト1につき、部隊全員の必殺技ゲージ初期値 +2%。上限 +10%。 | 「高コスト2枚＋低コスト4枚で少し余らせて先に撃つ」という選択肢が生まれる。上限を設けているため速攻一辺倒にはならない。 |
| 案B | 余剰コスト1につき、部隊全員の最大兵力 +1%。上限 +5%。 | 効果が地味で、意思決定を生みにくい。 |
| 案C | 変換しない。 | 実装は最も簡単だが、コストを使い切る以外の選択肢が消える。 |

案Aを暫定採用する。上限値は §7.1 のゲージ設計目標と併せて検証する。

### 4.6 武将の強さとバランス指標

同一の武将格または同一コスト帯に属する武将は、役割・兵種・相手編成によって強さが入れ替わる設計とする。完全な横並びは目指さない。

| 原則 | 内容 |
| --- | --- |
| 同格内の上位互換を避ける | 同じコストで、主要局面のすべてにおいて別武将を上回るカードを作らない。 |
| 低コストは役割で採用させる | 足止め、ゲージ支援、特定兵種対策、撤退時効果など、低い総合値でも編成上必要な機能を持たせる。 |
| 高コストは枠効率を持つ | 1枠で大きな戦力を持つ一方、残り5枠のコストを圧迫する。 |
| 数値検証を行う | 多数の編成・配置・乱数シードによる反復シミュレーションで勝率を確認する。 |

#### バランス指標［暫定・v0.1 から差し替え］

v0.1 の「理論戦力を基準値の±5％以内」は、単一スカラーとしての理論戦力が定義できないため測定できない。相性・配置・必殺技で強さが入れ替わる設計を前提にしている以上、なおさら定義不能である。測定可能な指標へ置き換える。

| 指標 | 目標値 | 測り方 |
| --- | --- | --- |
| 差し替え勝率 | 47–53% | 基準編成の1枠を同コスト帯の別カードへ差し替え、マッチ勝率を測る。範囲外は要調整。 |
| 採用率上限 | 単一カードで30%以下 | 同コスト帯内での採用シェア。超過は実質的な上位互換の存在を示す。 |
| 採用率下限 | 3%以上 | 下回るカードは役割が機能していない。 |
| 対策型の評価 | 想定採用局面での勝率で評価 | 平均勝率では過小評価されるため、対象兵種・対象編成に限定した勝率を別に測る。 |
| 検証規模 | 1条件あたり1,000シード以上 | ±5%のダメージ乱数と命中判定を吸収できる規模。 |

## 5. 戦場と兵種

### 5.1 配置盤面と対面関係

各部隊の6武将は、左翼・中央・右翼の3列と、前衛・後衛の2列からなる6枠へ1人ずつ配置する。相手側も左右反転した同一構造を使用する。

| 自軍配置 | 左翼 | 中央 | 右翼 |
| --- | --- | --- | --- |
| 前衛 | 前衛・左 | 前衛・中 | 前衛・右 |
| 後衛 | 後衛・左 | 後衛・中 | 後衛・右 |

#### 対面関係の明確化［暫定・新規］

v0.1 の「左右反転した同一構造」「基本は同じ列の敵と交戦」は、自軍左翼が敵の左翼と当たるのか右翼と当たるのかが読み手によって割れる。以下を確定させる。

盤面には3本のレーンがあり、両軍が向かい合う。自軍の左翼は敵軍の右翼と正対する。

| レーン | 自軍 | 敵軍 |
| --- | --- | --- |
| レーン1 | 左翼 | 右翼 |
| レーン2 | 中央 | 中央 |
| レーン3 | 右翼 | 左翼 |

これにより「相手は右翼を厚くする癖がある → こちらは左翼を厚くする」という読み合いが成立する。UI では正対関係が一目で分かる表示にする。

### 5.2 交戦・移動・標的選択［暫定・新規］

v0.1 が「次版で確定」としていた列移動・隣列支援・後衛突入を定義する。

#### 距離と移動

| 項目 | 暫定値 | 補足 |
| --- | --- | --- |
| レーン奥行き | 100単位 | 開戦時の両軍前衛間の距離。 |
| 後衛の位置 | 自軍前衛の後方15単位 | 前衛が撤退すると後衛が前衛位置へ前進する。 |
| 移動速度（歩兵／騎兵／弓兵） | 8／12／7（単位／秒） | 武将個別の移動速度パラメータの兵種標準値。 |
| 攻撃レンジ（歩兵／騎兵／弓兵） | 10／10／45（単位） | 弓兵は接敵前から攻撃できる。 |
| 隣列への移動時間 | 25単位分の移動として扱う | 移動速度が速いほど早く支援に入れる。 |

#### 交戦と標的選択

1. 各武将は開戦と同時に、正対するレーンの敵へ向かって前進する。
2. 敵との距離が自分の攻撃レンジ以内になった時点で攻撃を開始する。以後、攻撃間隔ごとに攻撃する。
3. 標的は、自レーンの敵のうち「前衛を優先し、前衛が複数いれば残兵力の少ない方」を選ぶ。
4. 攻撃レンジが後衛位置（前衛から15単位）まで届く武将は、自レーンの前衛が撤退していなくても後衛を狙える。弓兵のレンジ45はこれを満たす。これが「弓兵→歩兵」の三すくみの実装的な根拠となる。
5. 自レーンの敵が全員撤退した場合、隣接レーンへ支援移動する。移動先は「敵が多く残っているレーン」を優先し、同数なら中央を優先する。
6. 隣接レーンへ支援移動した武将は、そのレーンの標的選択規則に従う。元のレーンへは戻らない。

#### 突破

前衛が撤退したレーンでは、敵の前衛が後衛へ到達できる。到達までの時間は移動速度に依存する。実況上はこれを「突破」として記録する。

未決: 前衛越し攻撃を受ける側の被ダメージ補正、支援移動中の被攻撃可否、複数レーンが同時に空いた場合の優先順位。

### 5.3 兵種の三すくみ

| 有利関係 | 基本理由 | 戦闘上の表現［暫定］ |
| --- | --- | --- |
| 騎兵 → 弓兵 | 高速接近により遠距離攻撃を封じる。 | 移動速度12で接敵が早く、弓兵の接敵前攻撃回数を減らす。対弓兵ダメージ +15%。 |
| 弓兵 → 歩兵 | 接敵前に継続して兵力を削る。 | レンジ45により、歩兵が接敵するまでに複数回の先制攻撃を行う。対歩兵ダメージ +15%。 |
| 歩兵 → 騎兵 | 隊列・槍・盾によって突撃を受け止める。 | 対騎兵ダメージ +15%。さらに騎兵の突破所要時間を1.5倍にする（足止め）。 |

三すくみは単純な大幅ダメージ補正だけで決めず、移動・射程・突破・足止めといった挙動でも表現する。数値補正は、配置や必殺技で不利相性を覆せる範囲に抑える。有利補正を +15% に留めているのはこのためである。

未決: 同兵種同士の補正（1.0 固定でよいか）、兵種を追加する場合の扱い。三すくみは閉じた循環であるため、第4兵種を追加する場合はサブタイプまたは特性として実装し、循環を崩さない。

### 5.4 戦場条件［暫定・新規］

全武将が最初から使用可能かつ戦闘が完全に決定論的であるため、外部シミュレータによる総当たりで最適編成が求まり、メタが早期に収束する構造がある。これを緩和するため、マッチごとに戦場条件を設定する。

重要なのは、戦場条件を**編成期間の開始時（毎時06分）に両者へ同時公開する**点である。結果段階の乱数ではなく編成段階の入力となるため、「乱数より編成・配置の影響を大きくする」という §6.4 の方針と矛盾しない。

| 戦場条件 | 効果［暫定］ |
| --- | --- |
| 平原 | 騎兵の移動速度 +15%。 |
| 隘路 | 隣接レーンへの支援移動を禁止。前衛の被ダメージ −10%。 |
| 雨天 | 弓兵の命中率 −15%、攻撃レンジ −20%。 |
| 濃霧 | 全兵種の攻撃レンジ −30%。 |
| 平時 | 補正なし。 |

- 1マッチにつき1つの戦場条件を設定し、3つの部隊戦すべてに同じ条件を適用する。
- 両プレイヤーに同じ条件が適用される。
- 条件の抽選はマッチ確定時にサーバー側で行い、以後変更しない。

未決: 条件の種類と出現比率、レギュレーションごとに条件を変えるか、シーズンごとに条件セットを入れ替えるか。

## 6. 戦闘の最小単位と武将パラメータ

### 6.1 部隊と兵力［暫定・新規・最重要］

v0.1 では兵力／耐久値が「暫定」扱いだったが、本文の各所（残存兵力判定、実況の「兵力386減少」、統計項目）は既にこれを前提に書かれており、これなしでは戦闘が成立しない。ここで確定させる。

| 項目 | 定義 |
| --- | --- |
| 戦闘の最小単位 | 武将カード1枚は、武将本人とその兵からなる1部隊を表す。盤面上は1つの駒として扱う。 |
| 兵力 | その部隊が保持する兵の量。実質的な HP。武将カード固有値。 |
| 撤退 | 兵力が0になった時点で盤面から除外される。「撃破」ではなく「撤退」と呼ぶ。 |
| 残存兵力 | 撤退していない部隊の兵力合計。引き分け判定と統計に用いる。 |

#### 兵力の逓減（消耗係数）

兵力が減った部隊の攻撃力を下げるかどうかは、試合展開と逆転可能性を大きく左右する重要な分岐である。

| 案 | 内容 | 帰結 |
| --- | --- | --- |
| 案A | 逓減なし（兵力は純粋な HP） | 兵力1でも全力で戦う。逆転余地は残るが、三国志らしさが薄い。 |
| 案B | 完全逓減（攻撃力 ∝ 残兵力率） | 初手の有利がそのまま雪だるま式に拡大し、逆転がほぼ消える。 |
| 案C（推奨） | 緩やかな逓減（下限あり） | 消耗が有利につながるが、崩壊はしない。 |

案Cを暫定採用する。

```
消耗係数 = 0.6 + 0.4 × (残兵力 / 最大兵力)
```

残兵力100%で1.0、0%直前で0.6。消耗した部隊は弱くなるが、最低60%の火力は維持するため、支援や必殺技による逆転余地が残る。

#### 兵力の標準レンジ

| コスト帯 | 最大兵力の目安［暫定］ |
| --- | --- |
| 低コスト帯（1-3） | 800 – 1,400 |
| 中コスト帯（4-6） | 1,400 – 2,200 |
| 高コスト帯（7-10） | 2,200 – 3,200 |

兵種による偏りを設ける。歩兵は同コスト帯の上寄り、弓兵は下寄り、騎兵は中間とする。［暫定］

未決: 兵力を残したまま退く「閾値撤退」（残20%で自動撤退等）を採用するか。回復・再編を導入する場合に意味を持つが、パラメータが1つ増えるため v0.2 では採用しない。

### 6.2 ダメージ計算［暫定・新規］

```
消耗係数   = 0.6 + 0.4 × (残兵力 / 最大兵力)
基本ダメージ = 攻撃力 × 消耗係数 × 兵種補正 × 状態補正
軽減後     = 基本ダメージ × 100 / (100 + 防御力)
最終ダメージ = 軽減後 × クリティカル倍率 × ダメージ乱数
```

| 項目 | 内容 |
| --- | --- |
| 防御の方式 | 減算ではなく除算方式を採用する。減算方式は「防御力が攻撃力を上回ると無敵」という不連続点を生み、コスト設計を難しくするため。 |
| 定数 K | 100（暫定）。防御力100で被ダメージが半減する。 |
| 兵種補正 | 有利1.15／不利1.0／同兵種1.0（§5.3）。不利側にペナルティを与えず、有利側にボーナスを与える方式とする。 |
| 状態補正 | §6.5 の状態効果による攻撃力・防御力補正の合成値。 |
| クリティカル倍率 | 原則1.5倍。 |
| ダメージ乱数 | ±5%。 |
| 最低保証 | 最終ダメージは基本ダメージの10%を下回らない。膠着による時間切れ多発を防ぐ。 |
| 端数処理 | 各段階で整数へ切り捨てる（§8.4 の再現性要件）。 |

未決: 定数 K の値、必殺技ダメージが同じ式を使うか別式を持つか、防御力の標準レンジ。

### 6.3 武将パラメータ一覧

| 状態 | 項目 | 役割・定義 |
| --- | --- | --- |
| 確定 | コスト | 各レギュレーションの部隊上限に対して消費する編成値。 |
| 確定 | 兵種 | 歩兵・騎兵・弓兵のいずれか。兵種相性と挙動を決める。 |
| 確定 | 攻撃力 | 通常攻撃・一部必殺技の基礎ダメージに影響。 |
| 確定 | 防御力 | 受けるダメージの軽減に影響。 |
| 確定 | 移動速度 | 接敵、追撃、突破、隣列支援の所要時間に影響。 |
| 確定 | 攻撃レンジ | 攻撃可能な距離と、前衛越し攻撃の可否に影響。 |
| 確定 | 必殺技ゲージ上昇率 | 必殺技ゲージが最大になるまでの速さに影響。 |
| 確定 | 命中率 | 通常攻撃・命中判定を持つ効果が成功する確率の基礎値。 |
| 確定 | クリティカル率 | 通常攻撃等がクリティカルになる確率。 |
| **必須** | **最大兵力** | **撤退判定に使用する実質的な HP。v0.1 では「暫定」だったが、これなしでは戦闘が成立しないため必須項目とする。** |
| **必須** | **攻撃間隔** | **接敵後の攻撃頻度。兵種標準値（歩兵1.2秒／騎兵1.0秒／弓兵1.6秒）に武将個別補正を掛ける。［暫定］** |
| 暫定 | 回避補正 | 攻撃側命中率に対する防御側補正。独立パラメータとして持たず、兵種標準値＋移動速度から算出する。 |
| 確定 | 必殺技 | 武将カードごとに固定された技。ゲージ最大時に自動発動。 |

「兵力」と「耐久値」は v0.1 で併記されていたが、本版以降は「兵力」に統一する。

### 6.4 命中・クリティカルと乱数

命中率とクリティカル率は同じ編成でも結果が完全固定されない余地を作る。一方、1時間ごとのランク戦で運の影響が大きすぎると、編成改善が結果へ反映されにくくなるため、乱数幅は低めに設計する。

| 項目 | 暫定目安 | 補足 |
| --- | --- | --- |
| 最終命中率 | 50-100％の範囲 | 攻撃側命中率 − 対象の回避補正 ＋ 兵種・状態補正。 |
| 通常の命中率帯 | 75-100％程度 | 連続回避だけで決着する状況を抑える。 |
| クリティカル率 | 0-25％程度 | 武将の役割に応じて設定。 |
| クリティカル倍率 | 原則1.5倍 | 率と倍率の双方を個別化しすぎない。 |
| 通常ダメージ乱数 | ±5％程度 | 編成・配置の影響を乱数より大きくする。 |
| 必殺技 | 原則必中 | 妨害効果は別途、抵抗判定を持たせる余地あり。 |

### 6.5 状態効果（バフ・デバフ）［暫定・新規］

v0.1 には必殺技「東南の風」による命中率低下や「兵種・状態補正」への言及があるが、状態効果の共通ルールが存在しなかった。ここを決めずに必殺技を量産すると、後から全体の作り直しが必要になる。

| 分類 | 内容 | 例 |
| --- | --- | --- |
| 能力補正 | 攻撃力・防御力・移動速度・命中率・攻撃間隔などを増減。 | 攻撃力 +20%、命中率 −15% |
| 行動阻害 | 移動または攻撃を一定時間停止。 | 足止め、混乱 |
| 継続ダメージ | 一定間隔で兵力を減少。 | 火計 |
| 防護 | ダメージ軽減、状態効果の無効化。 | 陣形、鼓舞 |
| ゲージ操作 | 必殺技ゲージの増減。 | 士気高揚、封殺 |

#### 共通ルール

| 規則 | 内容 |
| --- | --- |
| 重複（同名） | 上書きせず、効果量が大きい方を採用する。持続時間は長い方を採用する。 |
| 重複（異名） | 同一能力への補正は加算合成する。 |
| 補正の上限 | 1つの能力に対する補正合計は −50% ～ +50% に丸める。 |
| 命中率の下限 | 状態効果を適用した後も、最終命中率は最低20%を保証する。 |
| 持続時間 | ティック数で保持する（§8.1）。表示上は秒に換算する。 |
| 解除 | 部隊の撤退時に、その部隊が付与した効果は解除しない（既に発生した影響は残る）。 |
| 抵抗判定 | 行動阻害系のみ抵抗判定を持つ。判定式は未決。 |

未決: 抵抗判定の式、効果の解除・打ち消し手段を持つ必殺技を用意するか、ゲージ操作系の上限。

## 7. 必殺技

- 各武将カードは、戦闘中に使用する固定必殺技を1つ持つ。
- ゲージが最大になった時点で自動発動し、プレイヤーは発動を保留・指定できない。
- 対象選択も技ごとに固定する。例：正面の敵、最も兵力が低い味方、敵後衛全体など。
- 同一人物の別バージョンは、異なる必殺技を持てる暫定案とする。

### 7.1 ゲージ設計目標［暫定・新規］

必殺技が原則必中（§6.4）かつ自動発動であるため、設計を誤ると「先に撃った方が勝つ」に収束し、ゲージ上昇率が他のすべてのパラメータを支配する。獲得源を決める前に、発動回数の目標を先に置く。

| 対象 | 1部隊戦（上限90秒）あたりの発動回数目標 |
| --- | --- |
| 主力・攻撃型 | 1〜2回 |
| 支援・妨害型 | 0〜1回 |
| 全体平均 | 1.2回程度 |

この目標に合わせてゲージ最大値と上昇率を調整する。標準的な武将が開戦から約60秒で1回目に到達することを基準とする。

### 7.2 ゲージ獲得源［暫定・新規］

ゲージ最大値を100とする。

| 獲得源 | 上昇量［暫定］ | 狙い |
| --- | --- | --- |
| 時間経過 | 必殺技ゲージ上昇率 × 1.0／秒（標準値1.0） | 交戦しない支援型でも発動機会を持てる。 |
| 与ダメージ | 与ダメージ ÷ 対象の最大兵力 × 20 | 攻撃型が早く到達する。 |
| 被ダメージ | 被ダメージ ÷ 自分の最大兵力 × 15 | 前衛で耐える役割が報われる。 |
| 敵の撤退 | +10（撤退させた部隊に付与） | 突破役が2回目に届く余地。 |
| 初期値 | 余剰コストにより 0〜+10（§4.5） | 編成段階の選択肢。 |

未決: 各係数の値、ゲージ封印・減少効果を持つ必殺技を認めるか、必殺技発動後のゲージを0に戻すか一部繰り越すか。

### 7.3 発動順序［暫定・新規］

複数武将が同一ティックで最大に達した場合、以下の順で一意に決定する。

1. ゲージ到達が早いティックの武将から発動。
2. 同一ティックなら、移動速度の高い順。
3. なお同値なら、配置枠の固定順序（前衛左 → 前衛中 → 前衛右 → 後衛左 → 後衛中 → 後衛右）。
4. なお同値なら、武将カードIDの昇順。

この規則により、同じシード・同じ編成であれば発動順序が必ず一致する（§8.4）。

## 8. 自動戦闘の実行原則

- 戦闘開始時に両軍の武将、配置、能力値、スキル、戦場条件、戦闘ルールのバージョンを確定する。
- サーバー側で試合固有の乱数シードを発行する。
- 一定間隔の戦闘ティックごとに、移動、標的選択、通常攻撃、命中、クリティカル、ゲージ増加、必殺技、撤退を処理する。
- 勝敗条件を満たした時点で各レギュレーション戦を終了し、3戦中2勝した側をマッチ勝者とする。
- 構造化された戦闘イベントから実況・統計・勝因候補を生成し、リプレイとして保存する。
- 同じルールバージョン・編成・戦場条件・乱数シードで再生した場合は同じ結果になるようにする。勝敗計算を文章生成AIへ委ねず、戦闘エンジンを唯一の正とする。

### 8.1 戦闘ティックの処理順序［暫定・新規］

v0.1 が次版の課題としていた「戦闘の1ティックで何が起きるか」を定義する。

| 項目 | 暫定値 |
| --- | --- |
| ティック長 | 0.1秒 |
| 1部隊戦の最大ティック数 | 900（90秒） |

各ティックで以下の順に処理する。順序を固定することが再現性の前提となる。

1. **状態効果の経過処理** — 持続時間を1ティック減算し、切れた効果を除去する。継続ダメージを適用する。
2. **移動** — 各部隊の位置を移動速度に応じて更新する。行動阻害中の部隊は移動しない。
3. **接敵判定** — 標的との距離が攻撃レンジ以内かを判定する。
4. **攻撃可否判定** — 前回攻撃からの経過が攻撃間隔に達しているかを判定する。
5. **標的選択** — §5.2 の規則で標的を決定する。
6. **命中判定** — 最終命中率で判定する。
7. **クリティカル判定** — クリティカル率で判定する。
8. **ダメージ適用** — §6.2 の式で兵力を減算する。
9. **ゲージ増加** — §7.2 の獲得源を合計して加算する。
10. **必殺技発動** — ゲージが最大の武将を §7.3 の順で発動させる。
11. **撤退判定** — 兵力0の部隊を盤面から除外する。
12. **勝敗判定** — §8.2 の条件を判定する。満たせば戦闘を終了する。

行動順は、同一処理ステップ内では「配置枠の固定順序（前衛左 → 前衛中 → 前衛右 → 後衛左 → 後衛中 → 後衛右）、先攻側 → 後攻側」で処理する。先攻側は乱数シードから決定論的に決める。

### 8.2 勝敗・終了条件［暫定・v0.1 の未決を解消］

| 条件 | 判定 |
| --- | --- |
| 全滅 | 一方の6部隊すべてが撤退した時点で、他方の勝利。 |
| 総大将撤退 | 総大将が撤退した時点で、その部隊戦は敗北（§4.2）。 |
| 時間切れ | 90秒（900ティック）経過時点で、残存兵力率（残存兵力合計 ÷ 最大兵力合計）の高い側の勝利。 |
| 引き分け | 残存兵力率の差が1%未満の場合、以下の順で判定する。①与ダメージ合計 ②残存部隊数 ③編成合計コストの低い側（少ないコストで並んだ側を評価） ④それでも同値なら引き分けとし、双方0.5勝として扱う。 |

| 項目 | 暫定案 | 理由 |
| --- | --- | --- |
| 3戦目の実行 | 2勝が確定していても全3戦を実行する。 | 実況の視聴体験を保つ。3-0 と 2-1 の差をレート計算の補助指標に使う余地を残す（§10）。 |
| 実行順序 | 低コスト戦 → 中コスト戦 → 高コスト戦 | 直列実行のため視聴が1本で済む。主力戦が最後に来るため、2-1 の逆転がドラマになる。 |
| 所要時間 | 最大 90秒 × 3 ＋ 戦間10秒 × 2 ＝ 4分50秒 | §3 の時間割（00-06分で結果確定）に収まる。 |

未決: 総大将撤退を即敗北とするか、残存兵力判定に委ねる減点方式にするか。即敗北は「総大将を狙う」という明確な戦術を生む一方、後衛に隠すのが常に最適になる恐れがある。§4.6 の検証で決める。

### 8.3 3部隊戦の独立性と実行順序［暫定・新規］

- 3つの部隊戦は完全に独立する。兵力、必殺技ゲージ、状態効果を戦間で持ち越さない。
- 各部隊戦は独立した乱数シードを持つ（マッチシードから決定論的に導出する）。
- 実行順序は低 → 中 → 高で固定する。
- 前の部隊戦の結果が後の部隊戦の戦闘処理へ影響することはない。

### 8.4 決定論と再現性の実装制約［暫定・新規］

「同じシードで同じ結果」を実際に保証するには、以下の制約が必要になる。方式は固定しないが、要件として記述する。

| 要件 | 内容 |
| --- | --- |
| 数値演算 | ダメージ計算・位置計算・ゲージ計算はすべて整数または固定小数点で行う。浮動小数点は実行環境・言語・最適化設定によって結果が変わり、再現性が崩れる。 |
| 乱数 | シードから決定論的に生成する疑似乱数を用いる。乱数の消費順序は §8.1 の処理順序に厳密に従う。 |
| リプレイの正 | リプレイは戦闘イベントログを正とし、再シミュレーションに依存しない。ルールバージョンが上がっても過去のリプレイが壊れないようにするため。 |
| バージョン記録 | 各部隊戦に、適用したルールバージョンとデータバージョンを記録する。 |
| 検証 | ルール変更のたびに、保存済みイベントログと再シミュレーション結果の一致を回帰テストで確認する（同一バージョン内で）。 |

## 9. テキスト実況・リプレイ

実況は、勝敗を演出するだけでなく「何が機能し、どこで崩れたか」を理解する攻略手段とする。通常攻撃を1発ずつ無制限に表示せず、数秒単位の集約と重要イベントを組み合わせる。

| 表示レイヤー | 内容 |
| --- | --- |
| 結果サマリー | 3戦の勝敗、マッチ結果、残存兵力、MVP、ランク変動。 |
| 実況リプレイ | 時刻順の主要攻撃、命中・回避、クリティカル、突破、必殺技、撤退、勝敗。 |
| 詳細統計 | 与ダメージ、被ダメージ、命中率、クリティカル率、必殺技発動回数、足止め時間など。 |
| 攻略ヒント | 戦闘イベントから機械的に抽出した勝因・敗因・改善候補。 |

### 9.1 実況表示例

1部隊戦の上限を90秒としたため、v0.1 の例（2分03秒）を尺に合わせて修正した。

```
【00:00】 開戦。張遼隊が右翼から急速に前進。
【00:08】 黄忠が張遼へ斉射。3射中2射命中、兵力386減少。
【00:11】 張遼の攻撃がクリティカル。黄忠の護衛を突破。
【00:17】 楽進が張遼を迎撃。兵種有利により突撃を阻止。
【00:28】 諸葛亮の必殺技「東南の風」が自動発動。敵中央・右翼の命中率が低下。
【00:42】 張遼が撤退。右翼の騎兵突破は失敗。
【01:04】 左翼が崩れ、趙雲が敵後衛へ到達。
【01:22】 敵総大将が撤退。種橋軍の勝利。
```

### 9.2 攻略ヒントの生成原則

- 戦闘エンジンが記録した事実だけを根拠にする。
- 「ゲージ92％で撤退」「敵騎兵を42秒足止め」「弓兵が接敵前に6回攻撃」など、原因と結果を結ぶ。
- 自由作文だけで勝因を推測せず、条件判定とテンプレートを基本とする。文章生成AIを使う場合も、確定イベントの言い換えに限定する。
- プレイヤーへ唯一の正解編成を提示せず、改善余地と観察ポイントを示す。

> **攻略ヒント例** 左翼の歩兵が敵騎兵を42秒間足止めしたため、後衛の弓兵は通常より6回多く攻撃できました。右翼の支援武将は必殺技ゲージ92％で撤退しており、前衛の耐久を補うと発動できる可能性があります。

未決: 集約秒数、全文ログと簡易ログの切り替え、保存期間、検索・共有。

## 12. オンボーディングと継続動機［新規］

v0.1 に記載がなかった領域だが、初期版の検証（編成研究が成立するか）を実施するには最低限の設計が要る。

### 12.1 初期の選択負荷

60人の武将から18人を選び、3部隊へ配分し、6枠へ配置し、総大将を決める。この初回体験は負荷が高すぎる。

| 対策 | 内容 |
| --- | --- |
| 推奨編成テンプレート | 兵種構成の異なるテンプレートを5〜8種類用意し、初回はここから選ぶだけで参加できるようにする。［暫定］ |
| 段階的な解禁 | 最初は高コスト戦のみ、数マッチ後に3部隊すべてを開放する案も検討する。［未決］ |
| 編成の妥当性チェック | 登録時に、コスト超過・人物重複・総大将未指定を検出して表示する。 |

### 12.2 継続動機

勝利によって得られるものが階級のみでは、長期の目標が存在しない。

| 候補 | 内容 |
| --- | --- |
| シーズン制 | 一定期間で階級をリセットし、到達階級に応じた記録・称号を残す。［暫定］ |
| 実績 | 「弓兵のみで勝利」「総大将を守り切って10勝」など、編成研究を促す実績。［暫定］ |
| 統計の蓄積 | 自分の採用武将・勝率・得意兵種の履歴を可視化する。［暫定］ |

いずれも戦闘能力には影響させない（§1.2）。

## 付録A. 用語

| 用語 | 定義 |
| --- | --- |
| マッチ | 1人対1人で行う3レギュレーション全体。2勝した側が勝者。 |
| 部隊戦 | 1つのレギュレーションで行う6人対6人の自動戦闘。 |
| レーン | 盤面の3本の縦筋。自軍左翼は敵軍右翼と正対する（§5.1）。 |
| 総大将 | 各部隊で1人指名する武将。撤退は敗北条件のひとつ（§4.2）。 |
| 兵力 | 武将部隊が保持する実質的な HP。0で撤退する。v0.1 の「耐久値」は本語に統一。 |
| 消耗係数 | 残兵力率に応じた攻撃力の逓減係数（§6.1）。 |
| 撤退 | 兵力0により盤面から除外されること。 |
| 対戦階級 | プレイヤーの到達段階。ランクとも呼ばれるが、武将側の格と区別する。 |
| レート | 対戦相手の選定と実力評価に使う数値。 |
| 武将格 | 武将カードの理論上の強さを整理する帯。採用の要否は今後確定。 |
| コスト | 部隊編成時に消費する値。各レギュレーションに上限がある。 |
| 余剰コスト | 上限から実際の合計コストを引いた値。初期ゲージへ変換する（§4.5）。 |
| 人物ID | 曹操、劉備など人物そのものを表し、別バージョン間の重複制限に使う。 |
| 武将カードID | 同じ人物の時代・逸話・兵種・能力が異なる個別バージョン。 |
| 公開スナップショット | 次戦相手に見せる、直前マッチ時点の確定情報。現在編成とは切り離す。 |
| 戦場条件 | マッチごとに設定される天候・地形。編成期間の開始時に公開される（§5.4）。 |
| レート対象マッチ／練習戦 | レートと階級が変動するマッチと、変動しないマッチ（§3.1）。 |
| ティック | 戦闘処理の最小時間単位。0.1秒［暫定］。 |
