# 騎兵の一撃離脱 — 常在型特性か兵法かの案（メモ）

テストプレイの提案（2026-08-26）:

> 迂回の応用でダメージ受けない時間を作るとかなんか工夫がいるんだと思うわ
> 迂回→離脱→突撃→迂回みたいなのを繰り返せるとかでもいいと思うけど
> 強くなりすぎないように注意したうえで

**いまは着手しない。** §7.108 で迂回の判定を直しただけで騎兵は 15.8% → 46.6% まで
戻り、7つの型の幅も 59.8 → 22.6 に締まった。ここへ機構を足すと強くなりすぎる公算が
高い。**盤面の釣り合いの話としては解決済み**で、これは「騎兵に一撃離脱の手触りを
持たせたいか」という設計の話として残す。

---

## なぜ機構として筋が通るか

騎兵は構造的に壁に向いていない（§7.108）。

- 防御 42.3（歩兵 56.6）
- **耐久役の札が1枚も無い**（近接の耐久21枚は全部歩兵）
- 規則で前衛は近接だけなので、騎兵デッキは必ず騎兵で壁をやらされる

だから騎兵の生きる道は「留まらないこと」にある。いまの迂回は**開戦時に1回だけ
経路を決める**（`_plan_paths`）ので、回り込んだら後衛に取り付いてそこで乱戦になる。
一撃離脱は「取り付いて、突撃の勢いが切れる前に離れ、また溜めて突っ込む」形で、
**`CHARGE_BONUS` / `CHARGE_TAU` の資源をもう一度使う**動きになる。

盤面の既存の部品と噛み合う:

| 部品 | いまの値 | 一撃離脱との関係 |
| --- | --- | --- |
| `CHARGE_BONUS` | 0.6 | 取り付いた直後の上乗せ。離脱で再使用できる |
| `CHARGE_TAU` | 12.0秒 | 勢いが失われる時定数。離脱の判断はここを基準に |
| `u.melee` | — | 接敵中だけ進む累積時間。離脱中は止まる（実装済み） |
| `DETOUR_MID` | 0.6 | 敵の削りの出どころで回り込みを決める（§7.108） |

`u.melee` が接敵中しか進まないのは実装済みなので、**離脱すれば勢いが回復する土台は
既にある**。足りないのは「経路を戦闘中に組み直す」ところだけ。

## 実装の形（案）

### 案A: 常在型の固有特性「一撃離脱」

`traits.csv` に常在型で追加。持つ札の騎兵だけが、接敵から一定秒で自動的に離脱し、
間合いを取ってから再突撃する。

- **利点**: 札を選べば手に入る＝プレイヤーの選択になる。値段が付けられる
  （`design.trait_value`）。全騎兵が強くなるわけではないので、釣り合いを壊しにくい
- **難点**: 常在型は戦闘中の瞬間を持たないので実況に出ない（§9.3）。せっかくの
  派手な動きが見えない。**離脱と再突撃を実況の出来事として出す**なら、常在型では
  なく別の器が要る
- **値段**: `CHARGE_BONUS` を何回使えるかで決まる。1戦の長さ（250〜300秒）と
  `CHARGE_TAU`（12秒）から、離脱の間隔しだいで 2〜5回。**回数を上限で縛る**のが
  安全（§6.6 の誘発型と同じく「1戦N回まで」）

### 案B: 兵法の効果として

`skills.csv` に「離脱」の効果語を足す。ゲージが溜まったら離脱＋再突撃。

- **利点**: ゲージが天然の上限になる（消費ゲージ%で回数が決まる）。実況に出る。
  値段は `design.effect_value` の器に乗る
- **難点**: 兵法の枠を1つ使う。騎兵の札に偏って配ることになる
- **効果語の案**: `離脱 N秒` — N秒かけて間合いを取り直し、`u.melee` を 0 へ戻す。
  その間は敵前衛の攻撃が届かない（射程 0 の近接だけ。弓は届く）

### 案C: 兵種の素の挙動（全騎兵）

`_plan_paths` を「開戦時に1回」から「接敵から `CHARGE_TAU` × k 秒で組み直す」へ。

- **利点**: 騎兵という兵種の個性がはっきりする。札を選ばなくてよい
- **難点**: **全騎兵が強くなるので釣り合いを丸ごと測り直し**になる。§7.108 で
  ちょうど収まったところなので、いま触ると何が効いたのか分からなくなる。
  やるなら他の変更と混ぜない

## 強くなりすぎないための歯止め

**必ず入れる:**

1. **回数の上限** — 常在型なら「1戦N回まで」、兵法ならゲージが上限になる
2. **離脱中は無敵にしない** — 敵前衛の近接は届かなくなるが、**弓は届く**。
   「ダメージを受けない時間」を作ると、それ自体が強力すぎる資源になる
3. **離脱に時間の代償** — 間合いを取り直す間は攻撃していない。`CHARGE_BONUS` の
   上乗せぶんが、離脱で失った攻撃時間を上回らないと割に合わない、という形にする

**測り方:**

- `tools/ladder_top.py combo` で ③鶴騎4弓2・⑤鶴騎3歩1 が **46.6% / 38.5% から
  どれだけ動くか**を見る。7種の幅（いま 22.6）が広がったら入れすぎ
- 離脱の間隔を掃引して、**幅が最小になる点**を採る（§7.108 と同じ基準）
- `tools/senki_check.py` で物語の坂が崩れないか。敵デッキに騎兵の居る戦が
  難しくなる

**やってはいけないこと:**

- `_plan_paths` の組み直しと `CHARGE_BONUS` の値を同時に触る。どちらが効いたか
  分からなくなる（§7.105b「死んだつまみを掃引して効かないと結論しない」の裏返しで、
  **生きたつまみを2つ同時に回さない**）

## 未決

- 案A / B / C のどれを採るか。**実況に出したいなら B**、釣り合いを壊したくないなら A、
  騎兵という兵種の個性として押し出したいなら C
- 離脱の判断を何で決めるか。`u.melee` が `CHARGE_TAU` を超えたら、が素直だが、
  **崖を作らない**書き方が要る（§13）。連続量にするなら「勢いが残っているほど
  留まりやすい」形
- 離脱先。元の位置へ戻るのか、敵の別の隊へ回るのか。後者なら**狙いを変える**動きに
  なって面白いが、経路の組み直しが重くなる
