# 画像制作 依頼書 — 『三国布陣』武将顔絵ほか

この依頼書は**そのまま画像生成AIに渡せる**ように書いてある。作る人（またはAI）は
この文書と `portrait-list.csv`（120人ぶんの一覧）だけを見れば足りる。

---

## 0. いちばん大事なこと（3行）

1. **縦3:4のバストアップ**を120枚。ファイル名は**人物名そのまま**（例 `曹操.png`）。
2. **顔の中心を上から約1/3**に置く。UIが上寄せ横長・正方形・20px円の3通りに
   切り抜くので、そこを外すと顔が切れる（§3）。
3. 画風は**墨と朱と金の東洋画**で統一。既存ゲームの絵柄を真似ない（§7）。

---

## 1. これは何に使う画像か

ブラウザで動く三国志の自動戦闘ゲーム『三国布陣』の**武将カードの顔絵**。
プレイヤーは120人の武将から6人を選んで部隊を組む。顔絵は一覧・編成枠・
敵陣の紹介・登用の演出など**画面のいたるところに小さく出る**。

いまは仮の生成画像（勢力色の地に姓一文字）が出ている。これを差し替える。

---

## 2. 納品仕様

| 項目 | 指定 |
| --- | --- |
| 形式 | PNG（推奨）。jpg / webp も可。同名が複数あれば png が優先される |
| 寸法 | **480×640 px**（縦3:4）。最低 240×320 |
| ファイル名 | **人物名そのまま**（`portrait-list.csv` の「ファイル名」列をコピーする）。例: `曹操.png` `諸葛亮.png` `貂蝉.png` |
| 枚数 | 120枚（優先順は §8） |
| 背景 | **不透明**。暗い単色〜淡いにじみ（勢力色を薄く敷く程度）。透過PNGでも可 |
| 容量 | 1枚 300KB 以下が目安 |
| 文字 | **画像内に文字・署名・透かしを入れない**（名前はUI側が描く） |

置き場所は `sim/webui/portraits/`。ファイルを置いて画面を再読み込みするだけで
差し替わる（コード変更は不要）。無い人物は従来の生成画像のままなので、
**1枚ずつ増やしていける**。

---

## 3. 構図 — ここだけは外さないでほしい

UIは同じ画像を**3通りに切り抜く**。

| 使う場所 | 切り抜き | 画像のどこが見えるか |
| --- | --- | --- |
| 武将カードの顔 | 横長 4:3.4・**上寄せ** | 上から **0〜64%** |
| 編成枠・詳細 | 縦長 3:4〜3:3.8・中央 | ほぼ全体 |
| 敵陣の一覧 | **正方形**・中央 | 上下を切った中央 12〜88% |
| 登用チップ | **直径20pxの円**・中央 | 同上をさらに丸く |

したがって**顔は「上から15%〜60%」の帯に収める**のが唯一の正解になる。

- 頭頂は上から **8%以上** 下げる（詰めると切れる）
- **顔の中心（目の高さ）が上から 30〜35%** に来るように
- 肩から胸までを下半分に。腰から下は描かない
- 顔の向きは**正面〜斜め45度**、視線はこちら。極端なあおり・俯瞰は避ける
- 帽子・冠・兜の飾りが縦に長い場合は**画面から飛び出させず**、頭を少し下げる
- 顔は**大きめ**に。20px の円になっても誰か分かる濃さで（薄い線画は消える）

## 4. 画風 — **太線のマンガ調で確定**（2026-08-20）

候補4案（水墨・マンガ調・ドット絵・モノクロ劇画）を実寸で比べて**マンガ調に決定**。
理由は絵の好みではなく、**20pxの円まで縮んでも輪郭線が顔を保つ**こと、**勢力色が
面で出るので4勢力を色で見分けられる**こと、**120枚の統一が現実的**なこと。
**以後の119枚はこの絵柄に揃える**（1枚の完成度より、並べたときの統一が効く）。

- **輪郭は太い墨線**。強弱のある筆ペン調で、髪・髭・鎧の縁を締める。
  画像幅480pxに対して主線が**3〜5px**あるくらい太く（細い線は縮小で消える）
- **面はフラットな塗り**（セル塗り）。影は1〜2段まで、グラデーションに頼らない
- **色数を絞る**: 勢力色＋肌＋黒髪＋金の差し色＋暗い背景。多色にしない
- 背景は**暗い墨のにじみ**（紙の目を薄く）。人物と背景の**明度差を大きく**取り、
  顔が地から浮くように。UIの地色は `#14100c`（濃い墨）
- 顔立ちは**劇画寄り**。眉・目・鼻筋の線を強く。大きな瞳のアニメ絵にはしない
- 金具・冠・武具の飾りは**金＋黒線でくっきり**（小さくても質感が残る）
- 表情は**静。** 叫んでいる顔より、次の瞬間に動き出す静けさ
- 年齢・体格・髭・傷は史書と演義のイメージに沿って描き分ける（老将は老将らしく）

### 勢力の色（背景のにじみと装束の差し色に使う）

| 勢力 | 色 | 気配 |
| --- | --- | --- |
| 魏 | `#46689c` 藍 | 整然・冷たい理知 |
| 蜀 | `#47825a` 緑 | 義・温度のある情 |
| 呉 | `#a04343` 朱赤 | 水と炎・気鋭 |
| 群雄 | `#8a7640` 黄土 | 野性・無頼・土埃 |

### やらないこと

- 既存ゲーム（三國無双・三国志シリーズ等）の**絵柄・意匠の模倣**
- 写実的な実在人物の顔、実写合成
- 現代的なアニメ絵の記号（過度なデフォルメ・巨大な瞳・明るいパステル）
- 画面内の文字、ロゴ、枠飾り、キラキラのエフェクト過多

## 5. 兵種と役割で描き分ける

一覧CSVの「兵種」「役割」列が、そのカードの戦い方を表す。**同じ勢力でも
役割が違えば佇まいを変える**（プレイヤーはこの区別を絵で読み取る）。

| 兵種 | 装い |
| --- | --- |
| 歩兵 | 徒歩の重装。長柄・大刀、厚い胴鎧。地に足がついた構え |
| 騎兵 | 軽快。馬具・鞭・翻るマント。上体がわずかに前へ |
| 弓兵 | 弓か弩を携える。軽装で身軽、遠くを見る目 |
| （槍持ち） | 歩兵のうち槍を持つ者。穂先を画面内に少しだけ見せる |

| 役割 | 気配 |
| --- | --- |
| 火力 | 攻めの気迫。得物を構え、前へ出る |
| 耐久 | どっしり構える。盾・鎧が厚く、動じない目 |
| 支援 | 落ち着いた佇まい。書物・扇・采配などの小物 |
| 均衡 | 隙のない構え。攻守どちらにも見える自然体 |
| 瞬発 | 踏み込む直前の緊張。体をひねり、視線は鋭い |

「武勇」「知略」の数値（1〜100）も一覧にある。**武勇が高いほど筋骨と得物を、
知略が高いほど眼差しと知の小物を強く**。

## 7. 権利まわり（守ってほしいこと）

- 使う生成AIの**利用規約で商用利用と再配布が許されている**ことを確認する。
  確認した日付とサービス名・モデル名を控えておく
- **既存作品の絵柄・キャラクターデザインを指定しない**（「〇〇無双風」等は不可）
- 実在の人物の顔・写真を素材にしない
- 生成に使ったプロンプト（と可能なら seed）を `portraits/PROMPTS.txt` などに
  残す。後で描き直すときと、出所を説明するときに要る
- **素材の出所とライセンスの責任は置く人にある**（ゲーム側は何も焼き込まない）

## 8. 作る順番（全部一度に作らなくていい）

`portrait-list.csv` の「優先」列がそのまま順番。

1. **優先1 — 初期セット40人**（40枚）… 始めた人が最初に見る顔。ここが揃うと
   ゲームの見た目が一気に変わる
2. **優先2 — 章ボス10人**（10枚）… 張角・呂布・孫策・曹操・周瑜・呂蒙・陸遜・
   司馬懿ほか。演出の山場に出る
3. **優先3 — 残り70人**

数枚できた時点で一度入れて、小さい表示での見え方を確かめるのを勧める（§9）。

## 9. 出来上がりの確認（納品前チェック）

- [ ] ファイル名が `portrait-list.csv` の「ファイル名」と**1文字も違わない**
- [ ] 縦3:4・480×640 以上
- [ ] **20px の円に縮めても誰か分かる**（縮小して確認する）
- [ ] 上から64%で切っても顔が全部入っている（頭が切れていない）
- [ ] 正方形の中央切り抜きでも顔が入っている
- [ ] 画像内に文字・署名・透かしが無い
- [ ] 120枚で**主線の太さ・塗りの段数・彩度**が揃っている（並べて確認）
- [ ] 決定した絵柄（§4 太線マンガ調）から外れていない

**候補の絵柄を決めるとき**は `docs/design/portrait-preview.html` をブラウザで開き、
候補画像を放り込む。実際の5寸法（カード128px・詳細64px・編成枠30×38・敵陣42px・
登用チップ20px円）で並ぶので、**20pxで誰か分かるか**が一目で判る。

置いて確かめる手順:
1. `sim/webui/portraits/` に入れる
2. ゲームを開いて再読み込み（Ctrl+F5）
3. 編成画面の一覧・編成枠・戦記の敵陣・登用の演出で見る

## 10. おまけ（あると使える画像・任意）

顔絵が済んでから、余力があれば。**受け取ってから画面に組み込む**ので、
先に作っても置き場所は用意していない旨だけ承知してほしい。

| 用途 | 寸法 | 中身 |
| --- | --- | --- |
| 表紙の背景 | 1920×1080 | 名乗り画面の背に敷く。人物は描かず、陣幕・旗・霧の景。中央は暗く空ける（題字が乗る） |
| 戦場の背景 3枚 | 1600×900 | 汜水関（関門と山）／官渡（黄河と平野）／赤壁（長江と火）。実況画面の背に薄く敷く |
| 勢力の紋 4枚 | 512×512・透過 | 魏・蜀・呉・群雄。旗や印章の意匠。単色で抜けるように |

## 付録: 一覧表について

`portrait-list.csv`（120行）の列:

`優先 / ファイル名 / 人物 / カード名 / 勢力 / 勢力色 / 兵種 / 役割 / コスト /
武勇 / 知略 / 必殺技 / 台詞 / 装いの手掛かり / 気配の手掛かり`

- **カード名**は `関羽〔漢寿亭侯〕` のように字号が付く。これはそのカードが
  「いつの関羽か」を表す（画像の年齢・装いの手掛かりになる）
- **台詞**はそのカードの決めゼリフ。人物の気性が一行で分かるので、表情の
  手掛かりに使ってよい
- **必殺技**の名前も同様（例「単騎突入」「東南の風」）
