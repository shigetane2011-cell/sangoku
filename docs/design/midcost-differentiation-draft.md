## 2. 差別化の案（史実・演義の顔に寄せる）

書式は skills.csv の文法そのまま（ダメージ 威力X%／継続ダメージ／回復 攻撃力の
X%／攻撃力・防御力・命中率・移動速度 ±X%（秒）／混乱 X%（秒）／畏怖 -X%（秒）／
行動阻害 X秒／通常攻撃防御・兵法防御・兵法反射／代償 兵力X%／反動）。

### 2d. 関羽〔漢寿亭侯〕10

いま: 騎兵・**均衡**・兵力10,851・攻撃力102.7（呂布285・孫策202・孫堅204の
半分）・兵法「青龍偃月」= 敵1体（前衛の主力）へ威力1121%の素の一撃・特性 対呉。
弱く見える主因は**均衡役**（兵力へ振られて打点が同帯の半分）と、兵法に二段目が
無いこと。同コスト騎兵との差し替え実測は §3。

| 案 | 中身 | ねらい |
| --- | --- | --- |
| A（推し） | 役割 均衡→**火力**。兵法 **「青龍偃月」** ダメージ 威力1200% + 畏怖 -12%（25秒）→ 敵1体（前衛の主力）。特性 対呉は維持 | 武聖の一撃と威名（斬られた側の軍が怯む）。呉との因縁は特性に残す |
| B | 役割 均衡→**瞬発**（呂布と同じ）。兵法は A と同じ | 呂布の隣に並ぶ最高打点。ただし呂布と近くなる |
| C | 役割は均衡のまま、兵法 **「斬顔良」** ダメージ 威力1500% → 敵1体（兵力が最多） | 敵の大将格を一騎で斬る。耐久は残る |

A なら攻撃力は火力役の水準（200前後）へ上がり、兵力は7,000台へ落ちる。
宝物の「ゆかりボーナス」（関羽が青龍偃月刀を持つと上乗せ）は別案として
温存（§7.140 の相談メモ）。

## 3. 関羽の実測（差し替え比較・赤壁40・12性格×50種）

同じ土台（文聘・曹仁・郝昭＋李典・貂蝉＝27点）の6枚目を10コスト騎兵で
差し替え、12性格パネルと戦わせた勝率（±は1SE）:

| 6枚目 | 勝率 |
| --- | --- |
| 孫堅〔江東の虎〕 | 37.2% ±2.0 |
| **関羽〔漢寿亭侯〕** | **34.5% ±1.9** |
| 孫策〔小覇王〕 | 33.3% ±1.9 |
| 呂布〔飛将〕 | 22.8% ±1.7 |

**関羽は弱くない** — 同帯の真ん中で、孫策と同水準。「弱い感じ」の正体は
均衡役ゆえに帳面の攻撃力が同帯の半分（103 vs 200前後）に見えることと、
兵法に二段目が無い顔の薄さ。だから直すのは強さでなく**顔**（§2d の案A）。
むしろ目立つのは**呂布が10ポイント低い**こと（瞬発役で兵力6,223・防御寄せ
-0.3 の紙装甲が、壁3枚の土台でも先に溶けている疑い）。別件として要調査。

A は孫策と同じ体格になる（総合値は式の上で不変＝コスト中立）。

壁・軍師の案も全部コスト中立で、能力値はほぼ動かない（許褚 総合131→123、
曹真 123→129 程度）。**例外は龐統の連環の計**: 継続ダメージ300%（20秒）は
効果予算 11.8 で上限3.15を大きく超える — 実装時に威力・秒数を落として上限内
へ収めるか、「行動阻害 3秒 → 敵1列」（鎖でつながれて動けない）へ変える。
王双は現状が上限超え（2.11／1.80）で、流星鎚案（1.60）はむしろ収まる。
