## 2. 共通プロンプト（18枚すべてに付ける）

```
三国志戦略ゲーム用の武将ポートレート。太い黒の墨線、大きく単純化した水彩色面、古紙調の顔料テクスチャ、

最重要背景条件: 明るい勢力色を頭上から両肩の背後まで途切れずに回り込ませる。中央正方形内では両肩の外側に
勢力色または淡い象牙色が残る。肩の背後に黒い楔や暗い空洞を作らない。濃い墨色は四隅のみに限定し、
中央正方形の約70%を明色・勢力色とする。

表情は静。叫ぶ顔ではなく、次の瞬間に動き出す静けさ。金具・冠・武具の飾りは金＋黒線でくっきり。
年齢・体格・髭・傷は史書と演義のイメージに沿って描き分ける。

禁止: 文字、数字、印章、ロゴ、透かし、額縁、複数人物、馬の頭、余分な手足。小道具は簡略化し、顔に重ねない。
既存のゲーム・作家・キャラクターの絵柄や意匠を真似ない。現代的なアニメの誇張（巨大な瞳・パステル）や
写実的な実在人物の顔にしない。
```

勢力の色: 魏 `#46689c` 藍（整然・冷たい理知）／蜀 `#47825a` 緑（義・温度のある情）／呉 `#a04343` 朱赤（水と炎・気鋭）／
群雄 `#8a7640` 黄土（野性・無頼・土埃）。
