# 武将顔絵 発注書 — 呂布の2版（〔飛将〕・〔虓虎〕）

§7.171 で呂布の2版は別の戦い方になった（**飛将＝弓馬の名手・手数で射抜く／虓虎＝猛虎の一撃と虎嘯**）。顔絵も版ごとに
分ける。画面の解決順（§7.135）は「版の絵 → 人物の絵 → 置き絵」なので、`呂布〔飛将〕.png` と `呂布〔虓虎〕.png` を置けば
それぞれの札に出て、**今の `呂布.png` はそのまま残す**（登用など人物単位の表示のフォールバック）。

## 3. 個別指定

**呂布〔飛将〕 / 群雄・黄土 #8a7640 / 騎兵・瞬発 / 武勇100 知略26**
兵法「轅門射戟」（残り兵力の最も少ない敵を何度も射抜く・手数）、特性「人中の呂布」（敵が崩れるたび追い撃ち）。
参照と同じ顔の呂布。**強弓を引き絞る直前**の姿。弓は画面を斜めに横切らせ、矢は画面内に収め、敵は描かない。軽めの
騎兵甲（革と小札）、赤い肩布は小さく、紫金冠の羽飾りは風になびく。背景は明るい黄土〜象牙を頭上から両肩へ。遠くの的を
見据える冷たい集中、口は結ぶ。**方天画戟は出さない**（虓虎と見分けるため）。

**呂布〔虓虎〕 / 群雄・黄土 #8a7640 / 騎兵・瞬発 / 武勇100 知略26**
兵法「虎嘯」（敵後衛へ突っ込み、吼えて相手の兵法の気を萎えさせる）、特性「鬼神」（手負いになると敵前衛が怯える）。
参照と同じ顔の呂布。**方天画戟の月牙（三日月の刃）を顔の横から画面端にかけて大きく**。重い小札鎧に虎の毛皮の襟か
肩掛け（縞は太く簡略化）、赤黒い外套。口を少し開き、牙を剥くように吼える直前の表情。背景は黄土に濃い赤の斑を
頭上から両肩へ回すが、明るさは規定どおり（中央の正方形の7割を明色に）。**弓は出さない**。
