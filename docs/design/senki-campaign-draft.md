# 戦記（討伐→登用キャンペーン）たたき台 v0.1

> 位置づけ: **相談用のたたき台**。承認されたら spec v0.5 に §7.60 として編入する。
> 決めるべきことは二つ — ①初期セット40人の線引き ②章立て（誰をどこで登用させるか）。
> ここではその二つを具体名で置き、残りは設計方針だけ記す。

## 0. 骨子（前提の再確認）

- 物語は書かない。1話 ＝ **敵の固定デッキ1つ＋前口上2〜3行＋登用**（会話・分岐なし）。
- プレイヤーは在野の無名君主（自分の武号）。演義の名場面を外側から渡り歩き、
  **倒した名将を登用して自軍に加える**（曹操伝・無双の型）。
- 兼務: 解放システムの配達手段 ／ 実質チュートリアル ／ 過疎期のソロコンテンツ。
- 実装は既存の流用: ダミー対戦（free_battle系）・リプレイ魚拓・軍師の見立て・恩賞の付与口。
  エンジン新機構なし。本体は敵デッキのデータ作り。

## 3. 解放の口（整理）

1. **戦記の登用（本線）**: 上表の80人。
2. **日次恩賞（補助）**: 既存のまま。特性は従来どおり、武将解放は行わない
   （戦記と二重にすると配分管理が壊れる）。
3. 課金するなら装飾（顔絵枠・称号・家紋）と時間（兵符補充）のみ。
   兵符上限10・同一相手1時間1回の縛りは課金分にも適用。

## 4. 実装メモ（着手時の設計点）

- players.db に `unlocks(player, general, got_at, source)` を1枚。roster API と
  編成画面・軍師に相談のたたき台生成を解放済みでフィルタ。
- 敵デッキは make_entry(caps=…) の手組みデータ（JSON か CSV）。章・戦番号・
  前口上・登用者・帯上限を1行に持つ。
- 進行度も ledger でよい（cleared: "senki:4-3" 形式）。
- 既存プレイヤー（＝本人のセーブ）は移行時に全解放フラグで救済。
- 戦記戦はレーティング・兵符と無関係（フリー対戦と同じ扱い）。リプレイは残す。

## 5. 決定事項（2026-08-19 相談で確定）

1. 章ボスは「格上＋2点」で行く。
2. 敗北ペナルティなし・何度でも再挑戦。
3. 全クリア後は周回モード「戦記番付」（§6）。ラダー送客のみ案は棄却。
4. 保留のまま実測待ち: 第1章クリアの張角10が18点帯で強すぎないか
   （18点で10点1枚は残り8点/5枠の重い賭けなので大丈夫と見る）。

## 6. 周回モード「戦記番付」（全クリア後）

- **2周に1点、ボスの家来が強い実在カードへ入れ替わる**（senki.lap_enemy）。
  大将と登用対象は固定・同兵種・後衛は弓か槍のまま・決定論
  （全プレイヤーに同一の敵）。差し替えなら**兵法ごと強くなる**。
  フル強化後は兵力+1.2%/周の乗算へ接続（打ち止めなし）。
  - 棄却の履歴（すべて実測）: ①恩賞上乗せ＝特性の値段が小さく数点で頭打ち
    ②+N点を cost へ等分＝コスト曲線が兵力に平らで兵法が買えず、雑兵構成の
    ボスは+30点でも脅威にならない ③兵力乗算のみ＝効くが兵法の穴が残り、
    毎周同じ敵の数字が増えるだけ。差し替え式は毎周パズルが更新される。
  - ペースも実測: 1点/周は壁が周回3〜5で急すぎ。2周に1点で最初の壁が
    周回8〜10（黄巾）・赤壁12〜14・五丈原26〜30。
- **周回の単位は章ボス8連戦**（張角→呂布→孫策→曹操→周瑜→呂蒙→陸遜→司馬懿）。
  残り32戦は一回きりの登用コンテンツのまま。
  （※40戦全周回が好みなら実装差はほぼない — 既定は8戦とする）
- **スコア**: 完走した周回のみ登録。その周の8戦の自軍残兵合計。
  番付は（周回数 → 総残兵）の辞書順。**リセットなし**（月次リセットのPvPと対になる恒久の縦軸）。
- **乱数式・再挑戦自由**: 戦闘は通常どおり乱数。振り直し狙いの再挑戦も
  やり込みとして正当（試行を重ねるほど各デッキの実力上限に収束する）。
  - シード固定（同一デッキ→同一結果）は**棄却**: 編成を写した瞬間に全員同点になり、
    番付が「誰が最初に見つけたか」の表に退化するため。
- **デッキ非公開**: 戦記番付の記録にデッキ魚拓を公開しない。番付経由の
  ワンクリック模倣を断つ。外部で共有されても乱数のおかげで同点にはならない
  （非公開＋乱数の二段構えで記録が個人のものになる）。
  自分の戦記リプレイは本人のみ閲覧可。「近ごろの合戦」には載せない。
- 記録にはパッチ版数（プール改訂）を添える。後のバランス調整で条件が変わるため、
  番付は「当時の記録」として読む（陸上の世界記録と同じ扱い）。
