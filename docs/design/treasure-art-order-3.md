# 『三国布陣』宝物イラスト発注書（追加3点）

先にお願いした18点の**追加分**です。同じセットに並びますので、
**画風・ライティング・縮尺感は既存18点に合わせてください**
（発注書: `treasure-art-order.md`）。

## 全体の指定（18点と同じ）

- **1枚につき品物ひとつだけ**。人物・背景・場面は描かないでください。
- **背景は透過**。ゲーム画面の暗い盤面（濃紺〜墨色）の上に置くので、
  暗色に沈まないよう輪郭がわずかに明るい色設計だと馴染みます。
- 画面では **26〜56px まで縮小表示**されます。遠目でシルエットが
  判別できることを最優先に、細部より形で描いてください。
  **文字・銘は描き込まない**でください。
- 3点とも品格の帯は **「中」＝上質** です。

## この3点だけの、大事な違い

既存18点は**名のある宝**（赤兎馬・伝国玉璽・倚天剣…）でしたが、
**この3点は持ち主の伝説がない「戦場の道具」です。**
大袈裟な装飾は要りません。**よく作られた実用品**として描いてください。
宝物棚に並べたとき、この3つだけ少し武骨に見える——それが正解です。

もうひとつ。3点はそれぞれ **「何かに強くなる代わりに、何かを失う」**
という性格を持っています。**失うほうの理由が絵から察せられる**と理想的です
（重い・短い、など）。下表の「弱さの気配」がそれにあたります。

## 各品の指定

### 1. `t_daijun.png` — 大楯（おおだて）／帯: 中

| | |
| --- | --- |
| 品物 | 歩兵が地面に据えて並べ、矢を防ぐ大きな盾。個人の盾ではなく**壁を作るための盾** |
| 絵の指定 | 一枚を立てた姿。**人の背丈ほどの縦長**で、木を張って革を巻き、鋲を打った簡素なもの。下端に地面へ据える石突き（杭）。やや斜めから見て**厚みと重さ**が出る角度に |
| あると良い | **矢が数本刺さっている**か、刺さった跡。「矢を防ぐもの」が一目で分かります |
| 弱さの気配 | **重い**こと。分厚さ・鋲・据えるための杭で「担いで走るのは難儀」と伝わるように |
| 避けたいこと | 紋章や豪奢な装飾。名家の飾り盾ではなく、数を揃えて並べる兵の道具です |

### 2. `t_bagai.png` — 馬鎧（うまよろい）／帯: 中

| | |
| --- | --- |

### 3. `t_tankyu.png` — 短弓（たんきゅう）／帯: 中

| | |
| --- | --- |
| 品物 | 馬上や乱戦でも扱える、短く反り返った弓 |
