# アイコン制作 依頼書 — 『三国布陣』兵種印・コスト印

顔絵（`portrait-brief.md`）と同じ絵柄・同じ世界のUI部品を作る依頼書。
**この文書だけを画像生成AIに渡せば足りる。**

---

## 0. 作るもの（全14枚）

| 種類 | 枚数 | ファイル名 | 用途 |
| --- | --- | --- | --- |
| 兵種印 | **4枚** | `typ-shield.png` `typ-spear.png` `typ-bow.png` `typ-cav.png` | どの兵科かを示す小印 |
| コスト印 | **10枚** | `cost-01.png` 〜 `cost-10.png` | 札の値段。**数が大きいほど豪華** |

置き場所は `sim/webui/icons/`（顔絵とは別フォルダ）。

---

## 1. 大前提 — ここを外すと使えない

- **背景は完全透過**（透過PNG）。顔絵と違い、札の絵や暗い盤面の上に直接乗る
- **表示は極小**。兵種印は **13px**、コスト印は **30px** で表示される。
  1〜2pxの細線・細かい文様・薄いグラデーションは**消えるか濁る**
- **画像の中に数字・文字を描かない。** コスト印の数字はゲーム側が上に重ねて描く
  （生成AIは数字の形を崩しやすく、崩れると値段を読み違える事故になる）
- 正方形。**兵種印 128×128 / コスト印 256×256**（縮小前提の余裕を持たせる）
- 図柄は**中央に寄せ、外周8%は余白**（丸く切り抜かれても欠けないように）

---

## 2. 画風（顔絵と揃える）

太い墨の輪郭・フラットな塗り・影は1〜2段・金は差し色。
`portrait-brief.md` §4 と同じ方針だが、**UI部品なのでさらに単純化**する:

- 輪郭は**太く均一**（128px幅に対して6〜8px相当）
- 面は**2〜3色まで**。中間色を作らない
- 光沢・発光・影の落とし込みは**入れない**（暗い盤面で浮くため）
- 東洋の意匠（雷文・龍・玉）を使ってよいが、**輪郭で読める形**にすること

---

## 3. 兵種印 4枚

**歩兵は2種類あるが、印の「形と色」は同じ**にして、**中の絵柄だけを変える**
（プレイヤーが「どちらも歩兵だ」と一目で分かるように）。

| ファイル | 兵種 | 色 | 中の絵柄 |
| --- | --- | --- | --- |
| `typ-shield.png` | 歩兵（盾） | **若草 `#a9c87e`** | 正面向きの**盾**。中央に縦の稜線 |
| `typ-spear.png` | 歩兵（槍） | **若草 `#a9c87e`**（盾と同色・同形） | **槍の穂先**を斜めに。柄は少しだけ |
| `typ-bow.png` | 弓兵 | **橙 `#e89a72`** | **弓に矢を番えた形**。弦は太めに |
| `typ-cav.png` | 騎兵 | **空色 `#85b4e2`** | **馬の首**（横向き・たてがみ付き） |

- 4枚とも**同じ外形の枠**（角の丸い菱形／円形など、統一されていれば形は任せる）に
  収め、枠は暗い墨色 `#14100c` の下地＋兵種色の図柄、という構成にする
- 背景の下地は透過。枠だけ薄く残すなら不透明度は控えめに

---

## 4. コスト印 10枚（①〜⑩・上ほど豪華）

札の左上に出る丸い印。**数字は入れない**（ゲームが重ねる）。
数が大きいほど**素材と装飾を格上げ**していく階段を作る:

| ファイル | 位置づけ | 素材と装飾 |
| --- | --- | --- |
| `cost-01.png` | 最も素朴 | 木札か素鉄の無地。縁だけ |
| `cost-02.png` | | 素鉄。細い一本縁 |
| `cost-03.png` | | 鉄。二重の縁 |
| `cost-04.png` | | 青銅。縁に点打ち |
| `cost-05.png` | 中位 | 青銅。縁に簡素な雷文 |
| `cost-06.png` | | 青銅＋金の差し。雷文が一周 |
| `cost-07.png` | | 金の縁＋小さな玉飾り |
| `cost-08.png` | | 金。縁に唐草、四方に玉 |
| `cost-09.png` | | 金＋龍の意匠が縁を巡る |
| `cost-10.png` | 最上位 | 金＋龍＋外周に光背（最も豪華） |

- **中央は必ず空ける**（直径の6割ほどを無地に）。そこに数字が乗る
- 中央の地色は**暗め**（`#241a08` 前後）。上に**明るい金色の数字**が乗るため、
  中央が明るいと数字が読めなくなる
- 外形は10枚とも**同じ直径の円**。豪華さは**縁の装飾**で表す（円が大きくなったり
  形が変わったりすると、並んだときガタつく）
- 1→10 で**連続した階段**に見えること。隣どうし（例 5と6）は似ていてよいが、
  1と10 は**別物の格**に見えること

## 6. 納品前チェック

- [ ] 透過PNG（白や黒の下地が残っていない）
- [ ] 兵種印 128×128 / コスト印 256×256 の正方形
- [ ] 画像内に数字・文字が無い
- [ ] **兵種印を13pxに縮めて、4種が見分けられる**
- [ ] **コスト印を30pxに縮めて、1と10が別物の格に見える**
- [ ] コスト印の中央が暗く、明るい数字を乗せて読める
- [ ] 10枚の円の直径が揃っている（重ねてズレない）

## 7. 受け取った後（ゲーム側の作業）

いまの兵種印とコスト印は**コードで描いたSVGと円**なので、画像が来たら
`sim/webui/icons/` に置いて差し替える。**数字はゲーム側が重ねる**ので、
コスト印は無地の中央を空けておくだけでよい。
画像が無いファイルは今の描画のまま出る（顔絵と同じで、1枚ずつ増やせる）。
