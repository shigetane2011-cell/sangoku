# スマホで遊べるようにする（自分と知人まで）

いまの Web 版は**鍵を持っていない**。名乗りを選ぶだけで誰にでもなれる。
だから「誰でも踏める場所に置く」は選べない。実際に選べるのは次の3つで、
下に行くほど手間と安全が増える。

| | 誰が遊べる | 手間 | 費用 | 認証 |
| --- | --- | --- | --- | --- |
| ① 同じ Wi-Fi | 自分（家の中） | 5分 | 0 | 家の網が壁 |
| ② トンネル＋認証 | 知人も（外から） | 30分 | 0 | Google等が壁 |
| ③ ちゃんと公開 | 誰でも | 数日 | 月額 | 自前で設計 |

**「とりあえず自分と知人だけ」なら ② が答え。** ①から順に足していける。

---

## ① 同じ Wi-Fi のスマホから（今すぐ）

PC で、いつもの起動に住所を足すだけ:

```
SANGOKU_HOST=0.0.0.0 python3 -m sim.web
```

起動時にこう出る:

```
http://localhost:8035  （Ctrl+C で終了）
同じ Wi-Fi のスマホから: http://192.168.x.x:8035
※ この口には鍵が無い。名乗るだけで誰にでもなれるので、
   同じ網に居る人しか触れない状態を保つこと。
試験用の口（/api/dev_*）は閉じている。
```

下の住所をスマホのブラウザに入れれば繋がる。**Safari / Chrome の共有 →
「ホーム画面に追加」**でアプリのように開く（額縁なしの一枚画面になる）。

つまずくとしたらここ:

- **繋がらない**: PC のファイアウォールが弾いている。macOS はシステム設定 →
  ネットワーク → ファイアウォール、Windows は初回に出る許可のダイアログで
  「プライベートネットワーク」を許可する。
- **住所が出ない / 違う**: PC が VPN に入っていると別の網の住所が出る。
  VPN を切るか、`ipconfig` / `ifconfig` で Wi-Fi 側の住所を自分で見る。
- **PC を閉じると切れる**: そういうもの。②でも同じ。

## ② 知人にも（外から遊べるようにする）

トンネルで外に出し、**認証は自分で持たずに外部へ預ける**。おすすめは
Cloudflare Tunnel ＋ Cloudflare Access（無料枠で50人まで）。知人はブラウザ
だけでよく、こちらはパスワードを一切預からない。

```
# 1. PC 側で
brew install cloudflared          # Windows は winget install cloudflared
cloudflared tunnel login          # ブラウザでドメインを選ぶ（要・自分のドメイン）
cloudflared tunnel create sangoku
cloudflared tunnel route dns sangoku sangoku.example.com

# 2. ~/.cloudflared/config.yml
#    tunnel: <作成時に出た ID>
#    credentials-file: ~/.cloudflared/<ID>.json
#    ingress:
#      - hostname: sangoku.example.com
#        service: http://localhost:8035
#      - service: http_status:404

# 3. ゲームとトンネルを両方あげる
SANGOKU_HOST=127.0.0.1 python3 -m sim.web    # 外へはトンネル経由だけ
cloudflared tunnel run sangoku
```

**ここで終わらせない。** この時点では住所を知る人は誰でも入れる。
Cloudflare のダッシュボード → Zero Trust → Access → Applications で
`sangoku.example.com` を登録し、ポリシーを「Emails → 自分と知人のアドレス」
にする。以後、踏むと Google ログインが挟まり、名簿に無い人は入れない。

**ドメインを持っていない場合**は、その場かぎりの試し撃ちなら
`cloudflared tunnel --url http://localhost:8035` で使い捨ての住所が出る。
ただし**これには認証が無い**ので、数分の動作確認までにとどめること。

**もっと簡単に済ませたいなら Tailscale。** 自分の PC と知人の端末に入れて
もらい、招待するだけで私設の網ができる。認証は Tailscale が持つ。欠点は
知人にアプリを入れてもらう必要があること。

## 出す前に見ておくこと

- **鍵が無い**。①②のどちらでも、**認証の壁の内側に置く**という一点だけは
  外さない。誰でも踏める住所に素で出さないこと。
- **試験用の口は自動で閉じる**。`SANGOKU_HOST` を手元以外にすると
  `/api/dev_*`（兵符満タン・天下即開催・戦記全クリア・恩賞全獲得）は 404 に
  なる。手元で開けたいときだけ `SANGOKU_DEV=1`。**外へ出したまま開けない。**
- **記録は1ファイル**。`sim/data/players.db` に全員ぶん入る。数人なら速さの
  問題は出ない。**このファイルには知人の表示名が入る**ので、git には入れない
  （.gitignore 済み）。控えを取るならこのファイルを丸ごとコピーする。
- **通信量**。編成の画面を一通り見て初回およそ 5.3MB、2回目からは 0.14MB
  （顔絵とアイコンは版の印を付けて返しているので、変えるまで引き直さない）。
  知人に「初回だけ Wi-Fi で開いて」と言えるなら、それが親切。
- **PC が起きている間だけ**遊べる。常時遊べるようにしたいなら③。
