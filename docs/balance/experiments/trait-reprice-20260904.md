# 固有特性の値札を引き直す（§7.152・特性の再較正）

**日付**: 2026-09-04 ／ **枝**: `claude/dev-handoff-balance-adjustments-8ezltu`
**テストプレイの裁定**: 「引き直し」「（予算の縮尺は誘発型に）かけない」
「（払いきれない札は）特性を変える — ただしコストは上げない。人物像を消さない」

## 0. 発端

§7.151 の回帰で 青嚢書 の回復が 6% ではなく 9% になっていた。追うと、予算の縮尺
（`SKILL_DUR_SCALE` / `SKILL_BURST_SCALE` = 1.5）が `_parse_skill` を通る全部に
掛かっていて、**固有特性と宝物の誘発型も 1.5倍 強くなっていた**。ところが
`design.TRAIT_PRICE` は効果文を読まない固定表（盤面で測った実測値）なので、
値札は旧盤面のまま。

## 1. 旧計器が使えなくなっていた

`python3 -m sim.field traits`（釣り合った合成軍どうし1局の残存差）は、§7.151 の
盤面で**段になっていた**。誘発型21種のうち **15種が判で押したように 0.1559**
（呼応も殿も影武者も同じ値）。決着が速くなって潰走が減り、「何かした/しない」の
二値しか残っていない。存在しない鍵を渡すと 0.0000 なので、発動はしている。
**同じ値の並びは計器を疑う合図**（§13）。

旧計器のコードにはもともとこう書いてある:
> 誘発の閾値 30%。ここを ROUT_UNIT(15%) にすると7種が死ぬ（釣り合った対戦では
> 誰もそこまで落ちないので、味方/敵の潰走を条件にする特性が一度も発動しない）

つまり**釣り合った合成軍では誘発条件がほとんど成立しない**のを、閾値を倍にして
誤魔化していた。実カード相手だと潰走も全滅も普通に起きる。

## 2. 計器を作り直した — `tools/trait_price.py`

相手を**実カードの性格パネル**（12性格 × 60種・官渡30）に替える。相手が局ごとに
違うので段が崩れ、小さい特性も別々の値になる。読み方は skill_price / effect_sweep と
同じ（§7.117）: Δ残存差（対応のある平均）÷ その札に1コスト点足したときの傾き。
前衛・後衛の両方で測り、高いほう＝安全側を採る（既存の表と同じ約束）。

- **勝敗（score）では測れない**。0/1 に丸まるので 80局では cheer も pursuit も
  ぴったり 0.000% と出る。残存差で読む。
- **本陣（command）は測れない**。総崩れが負けた側の残存差を大きく振るので符号ごと
  嘘になる（前衛 −34.5・後衛 −14.1 と出るが勝率では +5.3%。§7.52 に既述）。
  勝率の通貨で別測。
- 陣頭・馬前は前衛にしか効かないので後衛は 0.000（それでよい）。
- 1本ずつ控えへ書く（実行環境が2回入れ替わって測定が飛んだ）。

## 3. 「予算1.5倍のせい」ではなかった — 算数で決まる

殿は `防御力 +20%（20秒）`。縮尺が効くのは秒数だけなので 20秒 → 30秒、
**効き目はせいぜい1.5倍**。実測は 0.076 → 0.703 で **9.2倍**。1.5倍では届かない。
差の大半は旧計器が誘発型を過小評価していたぶんで、縮尺は上乗せ2割にすぎない。

（縮尺そのものを 1.0 にして比べる切り分けは失敗した — 合成カードの標準兵法まで
弱くなって盤面ごと変わり、常在の対照（陣頭）まで 1.68倍 動いた。特性の読み込み
だけを切り替える形に直した。）

## 4. 縮尺を外した（裁定「かけない」）

縮尺の理屈は「ゲージの供給を上げて発動が増えたぶんの補償」だが、**誘発型は
ゲージで撃たない** — 味方の潰走や自分の残兵で撃つので、供給を上げても発動回数は
増えない。補償する理由が無い。読み込みのあいだだけ立つ旗（`field.unscaled`）と
`Skill.scaled`（兵法 True／誘発 False）で、固有特性と宝物を縮尺から外した。
画面も同じ読み方へ揃えた（盤面20秒なのに画面30秒、を防ぐ）。

## 6. 払いきれない札の問題と、コストを上げない理由（テストプレイ）

名簿はコスト×兵種で 12枚ずつぴったり作ってある（コスト1: 歩3・騎3・弓6）。
コストを上げると分布が崩れ、18コスト戦場の主力（コスト1）が減って
「みんな同じデッキ」に近づく。**コストは上げない。**
コスト1〜2 で値上がりの大きい誘発型を持つ札は14枚（殿・救護・弔旗・遺志・死守・
鼓舞・執念・背水）— 低コスト札は誘発型の宝庫なので、数枚の例外処理では済まない。

安い特性への振替は人物像を消す（呂範〔子衡〕の殿は「殿を務める」宿老の像）。

**先に確かめること**: 殿はコスト1の呂範が持ってもコスト7の于禁が持っても同じ
値打ちか。誘発型は持ち手が生きていないと撃てず、1戦2回は長く立つ札ほど撃てる。
値打ちが持ち手のコストで違うなら、`TRAIT_PRICE_BY_PERSON`（酒乱で既にある）と
同じ理屈で**コスト帯ごとの値札**にすればよく、特性もコストも動かさずに済む。
違わないなら、軽い版の特性を新しく作る（テストプレイの提案）。→ §7 へ

**仮説は外れた。** 味方の潰走で撃つ型（殿・弔旗・弔い合戦）は、軍への効きが

持ち手の能力に乗る型（遺志・継戦・影武者）は高コストほど高いが、これらは
低コスト札で問題になっていない。表はキーごとに1つ・高いほう（安全側）のまま。
（コスト2 の列が全体に低いのは車台の勾配の癖と思われる — 判断には使わない。）

### 実デッキの的で測り直した — `tools/skill_panel.py`（新設）

その札＋合成の詰め物5枚（総30・弓は後衛）を実カードの性格パネル（12性格×60種・官渡30）に
当て、兵法あり／なしを同じ種で対にする。勝率の通貨と残存差の通貨（詰め物1枚の ±2 で局所勾配）。
handoff に書いてあった `campaign/reprice/skill_panel.py` は作業場ごと失われていたので作り直した。

| 陸抗（味方全体 +30%58秒・節制を両案から外して） | 72.4% | +7.50 ±1.92 | 1.54 | **2.79** | 6.36 | 0.44 |
| 蒋琬（味方後衛 +20%30秒） | 47.9% | +1.25 ±0.81 | 0.26 | **0.70** | 3.29 | 0.21 |
| 諸葛恪（敵正面2体 威力1300%・大技） | 61.5% | **+20.56** ±2.95 | 4.23 | **7.38** | 4.94 | 1.49 |

陸抗は最初 −6.53%（兵法を外すと勝つ）と出た — 節制が「自身の初回兵法後」に発動するので、
兵法を外すと節制の負の値まで消えて差が混ざる。`--strip-trait`（特性を両案から外す）で測り直した。

**兵法防御の倍率は 2.4倍 過大**。味方全体は2枚の比が揃う（0.40／0.44 → 0.42）のでその倍率
（5.429 → 2.280）。味方後衛は 蒋琬 が §7.151 前の値（÷5.557＝0.18）に近いので前の値へ

**諸葛恪〔元遜〕だけは本当に強い。** 兵法の値打ち 4.2〜7.4 に対して請求 3.90（上限）・
上限なしでも 4.94。ダメージの単価は §7.151 で中央値 1.02 と当たっているので器のせいではなく、
この札の噛み合わせ（弓兵の 822 攻撃 × 1300% × 正面2体の大技）。→ §13 で案を測る。
