# 休戦令 実装引き継ぎ

実装日: 2026-08-29。仕様の正本は `docs/spec/basic-game-spec-v0.5.md` §7.132、
全体の引き継ぎは `docs/handoff.md` 冒頭を参照。

## 実装したもの

- 天下を12時・21時から**毎時00分**へ変更
- 3デッキが揃っている人は自動参加。対戦相手は開催時に決め、事前公開しない
- 毎日8枚の**休戦令**。初期設定は0〜7時、8枠は分割可能
- ホームから「通常設定」と今日から7日分の「日別変更」を操作
- 開催2時間前で締切。過去・締切済みの枠は変更不可
- 休戦者は組合せ対象外。武名・報酬・戦歴は動かない
- 人間が奇数なら在野を1人外して偶数化。全人間が休戦なら在野だけの開催は省略
- ホームへ次回の参戦/休戦、復帰時刻、本日の天下成績を要約表示
- 同時アクセスの二重開催を `tenka_runs.serial` の主キーで防止
- 旧2回制からの初回切替では現在時までを済扱いにし、過去24時間を一括開催しない

## 画面と戦歴の追補

- 今日が動かせず明日を自動表示した時、選択中の8枠も明日から初期化する。
  旧版は見出しだけ明日、選択は今日になり、明日を誤って上書きできた
- 畳んだ要約は通常設定でなく**今日の有効設定**。連続時刻を `0〜8時` のように畳む
- 開催済みを「済」、未来だが2時間前を過ぎた枠を「締切」とサーバー判定で区別
- 保存後は同じ日・同じタブ・開いた設定欄を保ち、成功または失敗を欄内へ表示
- 自分の戦歴は上限40→200件。`すべて／天下／挑戦／軍議` で絞れ、天下は
  日別の勝敗へ畳む。APIは表示名と別に `mode_key` と地方日 `day` を返す

## 今回は変えていないもの

- 天下のElo K値。毎時化すると最大16戦/日になるため、実プレイヤーの初週分布を
  見てから調整する。現行の `k_of` は30戦でKが半分になる
- 戦闘・カードの数値。休戦令の導入でバランス定数は触っていない
- 定刻処理は従来どおり遅延評価。サーバーが停止していた開催は、次のアクセスで
  順に解決される。常時起動中は通常の毎時開催になる

## 運用上の注意

- 時刻は従来どおり**サーバー地方時**。日本向けサーバーでは `TZ=Asia/Tokyo` を
  明示すること
- `tenka_runs.state=failed` が出た開催は自動再実行しない。部分実行の上に重ねて
  レートを二重加算しないため。`error` を確認して手動判断する
- 公開時は既存方針どおり `/api/dev_tenka` を含む開発用APIを削除する
